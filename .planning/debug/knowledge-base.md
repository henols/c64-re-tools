## gsd-internals-leak-into-src — GSD planning vocabulary pervasive in product source and shipped skills
- **Date:** 2026-09-11
- **Error patterns:** no runtime error; silent content leak. `.planning/` path literal in a shipped file, `/gsd-*` command name addressed to an end user, `Phase N` / `plan NN-NN` citation, `D-NN` / `G-NN-N` id, dangling cross-reference to a planning artifact that does not exist in the consumer's checkout, two copies of one document disagreeing while one is labelled generated.
- **Root cause(s):** IMPORT — the MCP server and skills were extracted from another GSD-managed project (2026-08-09, b0975f4c) carrying 424 citations pointing at the DONOR repo's `.planning/` tree; decisive proof is that `.planning/RE-FINDINGS.md` is cited by 24 tracked `src/` files and five shipped SKILL.md footers and has never existed here at any commit; PRESCRIPTION — `/gsd-map-codebase` observed the imported style two days later and wrote it into `.planning/codebase/CONVENTIONS.md` §Comments as "the house style, not an exception", requiring plan ids and decision labels in every WHY header, projected into CLAUDE.md via the `GSD:conventions` marker; AMPLIFICATION — GSD's workflows make every discuss/execute agent READ that file and re-GENERATE it each milestone, and guard tests built along the way explicitly legalised "historical narration", taking the count 424 → 3196 in 33 days. The AND-gate fired: import alone is a static sweep, the convention alone would have produced citations that RESOLVE; only the conjunction produces unbounded growth of UNRESOLVABLE references.
- **Fix:** Repeal before sweep. `.planning/ENGINEERING_RULES.md` § 21 (hand-maintained, therefore not erasable by a regeneration) states the rule and explicitly overrides any future map-codebase run that re-describes citations as house style; CONVENTIONS.md §Comments rewritten to anchor a WHY header on an actionable REASON instead of a plan/decision id; `skills-planning-vocabulary.test.ts` added (eight categories over `src/skills/**`, one exemption derived from a file's own `## Phase N` headings so it cannot be granted by hand); all 276 violations across 47 shipped-skill files cleaned, including five copy-pasted SKILL.md footers telling end users to file findings in a path that never existed and two factually WRONG incident-directory claims corrected rather than merely stripped; a `.planning/` literal in a plugin-zip-shipped test replaced by an operator-supplied `C64_RE_CORPUS_IMAGE` env var, verified to still RUN (17/17) when supplied; `.planning/PROJECT.md`'s Constraints reconciled with CLAUDE.md's copy (stale Node floor, five bullets about a retired dependency, three missing measured qualifications) and `docs-constraints-sync.test.ts` added to hold them byte-identical.
- **Files changed:** `.planning/ENGINEERING_RULES.md`, `.planning/codebase/CONVENTIONS.md`, `.planning/PROJECT.md`, `.planning/ROADMAP.md`, `CLAUDE.md`, `src/mcp/vice/skills-planning-vocabulary.test.ts` (new), `src/mcp/vice/docs-constraints-sync.test.ts` (new), `src/mcp/vice/docs-linerefs.test.ts`, `src/mcp/vice/audit-integrity.test.ts`, `src/mcp/vice/README.md`, `src/mcp/vice/anno-cli.test.ts`, `src/mcp/vice/anno-cli-path-consumers.test.ts`, `src/mcp/vice/fixtures/c1541/README.md`, `scripts/audit-gate.mjs`, `src/skills/**` (47 files)
- **Why not caught:** No gate existed for this class on the shipped-skill surface. The project HAD drawn a line — `docs-dangling-refs.test.ts` forbids a phase number in a shipped string or template literal, `comment-phase-pointers.test.ts` deliberately declines a blanket ban and polices only staleness — but it drew it at RUNTIME-VISIBLE TEXT and exempted comments, which is correct for `src/mcp/vice/**` (reader = maintainer) and wrong for `src/skills/**` (reader = a plugin user with no `.planning/`). For the second half: `docs-linerefs.test.ts` already reads both constraint documents, but only four line numbers inside one bullet, so it could not see any other divergence between the two copies — and the marker comment `source:PROJECT.md` asserted a provenance relationship nothing verified.
- **Recurrence guard:** `src/mcp/vice/skills-planning-vocabulary.test.ts` (RED on the untouched tree with 276 violations in 47 files, green after); `src/mcp/vice/docs-constraints-sync.test.ts` (RED against the pre-reconciliation `PROJECT.md`, naming all twelve divergent positions; green after); `.planning/ENGINEERING_RULES.md` § 21; and Phase 51 as the measured backlog for the one surface still carrying the vocabulary (`src/mcp/vice/**`, 2384 occurrences across 88 shipped files), with the ordering trap recorded — widen the guard LAST.
