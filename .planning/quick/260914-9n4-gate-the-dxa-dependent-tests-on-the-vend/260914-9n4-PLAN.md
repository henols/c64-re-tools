uncovered residue on a runner is: nobody re-checks that a future `cwd` change does

host that has built dxa, it is checked on every run.

**Why that trade is correct.** The alternative is not "keep the coverage" — it is
"teach CI to produce the binary", which this project forbids outright: external
tools are detected and refused by name with the remedy, never installed, fetched or
built on demand. Between a named, greppable, require-variable-armable skip and a
red pipeline that blocks every release, the skip is the honest cost. It is one
test, its reason names itself and its remedy, and setting the require-variable on
any machine that should have the binary converts it back into a hard failure.
