## The schema, locked

This is the exact shape. Do not vary it; two later phases walk this tree.

Top level: `{ "schemaVersion": 1, "tools": { "<id>": ToolRecord, ... } }`.

`schemaVersion` is `1`. Open question resolved: include it. `anno-regbits.json` carries a
metadata banner and `tools-manifest.stock.json` carries none; one key now forecloses a future
"was this file ever versioned" question, and it costs nothing. Do **not** add a `_generated`
banner, a generator name or a digest pin — this file is hand-authored, has no generator to
drift against, and a banner claiming one would misrepresent authorship.

`ToolRecord`:
- `id` — string, byte-equal to the key it sits under.
- `unblocks` — object with two keys, both always present arrays, possibly empty:
  - `skills` — each value a real directory name under `src/skills/`.
  - `mcp` — each value a member of `HOST_TOOL_IDS` (`src/mcp/vice/host-tool.mts:181-193`).
- `versionFloor` — optional string. **Only** the `node` record may carry it.
- `remedies` — object keyed by platform. Permitted keys are exactly `linux`, `darwin`, `win32`
  and `universal`. Each value is an **ordered array** of remedy entries. A platform with no
  known remedy has its key absent — never an empty array, never null.

Remedy entry: `{ "ecosystem": string, "text": string, "provenance": string, "source": string }`.
- `ecosystem` — ASCII kebab-case identifier.
- `text` — one human sentence containing a command. Plain prose. Markdown code-span backticks
  are stripped; the Phase 62 generator re-adds formatting when it emits markdown, and Phase 60
  drops this string verbatim into a refusal sentence where backticks would be noise.
- `provenance` — exactly one of `measured`, `carried`, `authored`.
- `source` — for `carried`/`measured`, a repo-relative `path:line` (the path part must name a
  file that exists). For `authored`, an https URL to the tool's own upstream install page.

`universal` means "applies on every platform". A consumer resolving for a given
`process.platform` uses the specific platform key when present and falls back to `universal`.
A record may carry both.

**Signal:** `chosen` — "those disagree today, the declaration records which was chosen and why".

**The generalization.** A remedy string used to be *derived*: a reader hit whichever of four
scattered places they happened to reach, and whatever it said was the remedy. There was no
mechanism that could say two of them disagreed, because there was no third thing for either to
be measured against. This phase makes the remedy *chosen*: one record names the winner and a
docs file records why.

**The noun that is now primary:** the **declaration record** — one per tool id, in
`src/mcp/vice/prerequisites.json`. The inline literal in a refusal, the README table cell and
the SKILL.md troubleshooting row are demoted to details: each becomes a *source* a record cites,
not a place a reader consults.

**Decision: `add-alongside`, deliberately, for exactly one milestone.**

The correct move is promote, and promote is scheduled — but not here. `DECL-03` (every live
refusal sources its remedy from the declaration) is owned by Phase 60, because it edits
`host-tool.mts`, whose compiled artifact under `src/mcp/vice/resources/` is byte-guarded by
`resources-sync.test.ts`, and Phase 60 exists to isolate that first regeneration. `GEN-01`
(the README table generated from the declaration) is owned by Phase 62. So at the end of this
phase the declaration sits beside the still-live inline literals and **no shipped code path
reads it**. That is the roadmap's explicit sequencing, recorded as Departure 1, not an
oversight.

**Accepted debt, and what forces the promote.** For one milestone, two descriptions of the same
remedy coexist and nothing mechanically prevents them disagreeing. Two already-scheduled
requirements force the promote rather than leaving it to intent: `DECL-03` in Phase 60 demotes
every inline refusal literal to a read of the declaration, and `GEN-01`/`GEN-02` in Phase 62
demote the README table to generated output with a build-failing divergence guard. If either
slips out of this milestone, the debt becomes a standing one and should be re-raised.

**Companion invariant, accepted and wired into Task 1.** The citation validator — every
`carried`/`measured` `source` resolves to a file that exists, every `authored` `source` is an
https URL — encodes the generalized intent mechanically: a record may not claim a provenance it
cannot point at. It goes red the instant a future phase adds a record with a fabricated or
deleted source, which is exactly the way the singular "just word it yourself" assumption would
come back.
