<objective>
Prove the volatile-I/O carve by **disappearance**, on both import routes: with the flag,
the fixture's hardware accesses appear in the export as typed references; without it, they
vanish. Then prove a loader-owned block at the same address is handled by setting the flag on
the existing block, and that a memory conflict is loud rather than a silent fall-back to
non-volatile.

Purpose: this is the phase's fourth criterion and the oldest of this project's Standing
Constraints about Ghidra — under default settings three of four processor-port writes and a
border-colour write were eliminated, silently, with no warning. Applied to a raster loop that
deletes the entire visible effect of the program and reports success. An assertion that the
flag is present proves nothing; only the disappearance does.

Output: four live cases in `ghidra-live.test.ts` and one evidence file carrying both routes'
with-flag and without-flag reference sections.
</objective>

<decisions>

**D-36-13 — The removal happens in a scratch copy of the script, never in the committed
one.** Each without-flag case copies `VolatileCarve.java` into its own temporary workspace
root, removes the flag-setting from that copy, points `scriptPath` at the copy, runs, and
tears the root down. The committed script is read and never written — the same invariant plan
36-01's compile gate holds over the committed extension tree, and a verify command asserts it
here too. This is what lets the red be observed without a commit that must later be reverted.

**D-36-14 — Both routes, in two separate recorded runs, because the routes genuinely
differ.** MEASURED at plan time: a base-0 import of an image covering the first two pages
emits both language-block conflict lines, at an image size of 4096 bytes, so the trigger is
the image covering the zero page and the stack rather than the image being 64K. On that route
the loader owns a block covering the I/O page and the carve must split first and flag the
existing block; on the `.prg` route nothing covers it and the carve creates. A pre-script
proven on one route meets a conflict on the other it was never run against, which is exactly
what `GHID-03`'s amendment records.

</decisions>
