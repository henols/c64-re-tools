<objective>
Turn the playbooks that produce Markdown prose into playbooks that produce store entries, and make
CI check the tool names they now mention.

**A correction to carry into this plan.** The phase framing says a skill edit has a "mandatory
second site" in `installer/skills/`. That is not what the repo does: `/installer/skills/` is
**gitignored** (`.gitignore:40-43`), tracks zero files, and is regenerated by
`installer/scripts/sync-skills.mjs` on every `prepack`. So there is no second file to hand-edit —
the obligation is to *verify* that the generated copy picks the edit up, via
`npm run sync-skills` plus `node scripts/check-npm-packages.mjs`, and to make sure
`installer/skills/` is not committed. Record this correction in the SUMMARY so the next phase does
not go looking for a second site either.

**What changes conceptually.** D-24 makes the store canonical: recon's job becomes writing labels,
comments, block types and scopes into the `.regen2000proj` and then *generating* the memory map.
The template's empty rows are the artifact most likely to pull a future session back into
hand-authoring, so they go. D-25's confidence prefixes become the documented way a grade is
recorded, with the vocabulary unchanged (`confirmed code`, `probable code`, `confirmed data`,
`probable data`, `unknown`) and the template's own rule preserved: do not promote a row by editing
its grade.

**Two CI gates read this prose.** `check-skill-tool-coverage.mjs` (r2000-aware since plan 11-05)
and `check-skill-fork-honesty.mjs` (exemption scoped and bounded by plan 11-02). Any tool name and
any capability claim added here is checked. This plan also adds the non-vacuity floor plan 11-05
deliberately deferred: once prose names `r2000_*` tools, an extraction that finds none must fail.

Purpose: criterion 1's wording is about `c64-program-recon` specifically. The machinery exists after
plans 11-05 and 11-10; this is where the playbook starts using it.

Output: three edited SKILL.md files, a reshaped template, and a coverage gate with a real floor.
</objective>
