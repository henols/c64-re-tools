<objective>
Close the symbol loop in code, and pin the trap that makes it a loop rather than two dumps.

**The trap, measured.** `--import_lbl` under plain `--headless` **discards**: `main.rs:800-806`
imports into memory and then hits `if headless && !mcp_server { return Ok(()) }` with no save.
Verified live — two names imported, then `--export_lbl` from disk returned only the pre-existing
label. There is no CLI-only route for `R2000-15`. D-28's pairing (`--import_lbl` **plus**
`--mcp-server-stdio` **plus** an explicit `r2000_save_project`) is the only persistence path, and
plan 11-04's `buildImportLblArgs()` makes the bad combination unbuildable. This plan pins the trap
itself, so that builder's pairing is provably load-bearing.

**What `--export_lbl` actually exports.** User-defined labels only. Measured: an annotated project
emitted **one** line; the auto-generated `a_D011` / `a_D020` / `e_FFD2` externals were NOT
exported. So whatever criterion 4 claims flows out must be a **user** label, which means the store
must have been written to first — which is exactly why `DERIV-04` "had no producer" and why this
requirement exists. Do not write a test that expects `a_`-prefixed auto-labels in the exported
file; RESEARCH.md Open Question #2 also records that a `synthesizeProject()`-bootstrapped project
does not populate them at all.

**Decision this plan owns (`<decisions_you_own>` #6, the fixture for D-31): reuse the committed
`probe-illegal.prg`.** Reason: what is under test here is the round-trip **mechanism**, not a
program's structure, so the subject needs no vectors, tables or handlers; it is the only `.prg`
committed in this repo and the real corpus is deliberately per-consuming-project via
`releases.mjs`/`test-corpus.mjs` so tests stay portable; and both Phase 9's `--export_lbl` format
`pass` and plan 11-03's D-35 verified note are scoped to *this* fixture, so testing against it
keeps the claim and its evidence aligned rather than widening one without the other. Reference it
by path with a guard assertion that the path exists, so a moved fixture fails loudly. (Plan 11-07
made the opposite call for criterion 1, where the program's structure IS the subject.)

**Rule A20.** Static-analysis symbols going out to VICE and live-discovered symbols coming back
must flow through explicit adapter code; neither side may parse the other's internal
representation. `r2000-symbols.ts` is that adapter, and it reuses `stock-symbols.ts`'s parser
rather than adding this repo's third copy of the `al C:` format (`stock-symbols.ts` and
`acme.mjs`'s `curateLabels()` are the two that already exist).

Purpose: without this, criterion 4 has no mechanism to demonstrate and plan 11-11 has nothing to
walk through on a real emulator.

Output: the adapter, two CLI verbs, and a CI-runnable closed-loop test with the absent-before
assertion criterion 4's wording demands.
</objective>
