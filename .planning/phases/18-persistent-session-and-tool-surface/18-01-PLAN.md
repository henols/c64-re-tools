**Detector fired** (`pluralization`); the two matched snippets ("rewritten a
second time", "`!byte` fallback") are prose false positives, but a genuine
singular→plural transition exists underneath them and is recorded here.

- **The noun that is now primary:** `R2000Session` — a *held* regenerator2000
  child handle with a lifetime independent of any one logical operation. Before
  this phase there was exactly one session kind (`withR2000Session()`, whose
  identity *was* the call). After it there are two callers with different
  lifetime needs: CLI verbs (one-shot) and `r2000_*` MCP tool calls
  (long-lived).
- **Decision: `promote`.** `openR2000Session(projectPath, opts) → R2000Session`
  becomes the primary primitive in `r2000-mcp-client.ts`, and
  `withR2000Session()` is re-implemented as a thin
  open → run → close wrapper over it, keeping its exported signature, its
  contract and its existing tests byte-for-byte unchanged.
- **Rationale (one line):** promote leaves exactly **one** `spawn(` statement in
  the file, which makes D18-02's "no third spawn site" and the `--vice`
  invariant's guard-before-spawn placement structural rather than duplicated;
  add-alongside would have produced two spawn/handshake code paths in one
  module — precisely the drift shape research names for save timing.
- **Consistency with D18-07:** the one-shot contract is *kept*, not retired, and
  no CLI caller changes. Promote is about which primitive is implemented in
  terms of which, not about removing an export.
- **Companion invariant test (accepted, planned):** plan 18-03 task 3 adds a
  source-structural assertion that `r2000-mcp-client.ts` contains exactly one
  spawn call site and that `assertNoViceFlag(argv)` precedes it — the test goes
  red the instant a future phase reintroduces a second spawn path for a third
  session kind.
