<objective>
Run Phase 49's gate against the modified subject, and pre-register the
intentional differences before anything is measured.

Phase 49's gate already produced one real committed verdict. That verdict was
`acknowledged` under rule `R10`, against the UNMODIFIED subject. ROADMAP
criterion 4 requires the MODIFIED source to be reassembled through the same
gate. That is a new run against new inputs. The gate module needs no edit.

This plan also commits the allowlist that names the modified subject's
intentional differences, with a reason for each. The allowlist is committed here,
in wave 2. It is first compared under in wave 4. That gap in time is the point.
A difference predicted in advance and named in git is evidence. A difference
named after seeing the measurement is a fit.

Purpose: ROADMAP criterion 4 binds the modifiability demonstration to a
hazard-report finding. ROADMAP criterion 2 requires that a difference be resolved
by naming it in the allowlist with why it is intentional, never by widening the
mask.

Output: a gate-run test file for the modified subject, a machine-readable
findings document, and the committed allowlist.
</objective>
