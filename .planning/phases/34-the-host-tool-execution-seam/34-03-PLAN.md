<objective>
Enforce Ghidra's no-dot project-path rule in this project's code, before `analyzeHeadless`
is ever reached, and give every run its own project directory so the single-writer lock is
unreachable rather than guarded.

Purpose: `34-RESEARCH.md` Finding 2 ran real Ghidra 12.1.3 twice and found something the
ROADMAP's own framing does not state — the refusal walks the ENTIRE absolute project-location
path, not just the leaf, and it fires after 12-16 s of JVM startup with a hard exit 1. So a
client-side per-segment check is not merely tidier; it is the only way to satisfy criterion
3's literal wording ("refused before `analyzeHeadless` is ever reached"), because Ghidra's
own refusal necessarily happens inside a running `analyzeHeadless`.
Output: `ghidra-project.mts` (host-bound, pure), its unit suite, the `ghidra.analyze`
allowlist entry in `host-tool.mts`, and a recorded live transcript.
</objective>

Planner assumption **A-06 — `ghidra-project.mts` is a host-bound module, and
`host-tool.mts` value-imports it.** The rule must be enforced where `analyzeHeadless` is
actually spawned, which is inside the broker process, so the module must ship as a compiled
`resources/*.mjs`. A host-bound module importing a sibling by its `.mjs` specifier only
resolves inside `resources/` — which is precisely why plan 34-01's A-04 already has
`host-tool.test.ts` reaching the executor as the committed artifact. `ghidra-project.mts`
itself imports only `node:path` and `node:fs`, so `ghidra-project.test.ts` CAN import the
`.mts` source directly, and does.

Planner assumption **A-07 — the runs root is `<repoRoot>/tools/ghidra-runs/<runId>`.**
`install-resources.ts`'s `installTargetDir(root) = join(root, "tools")` is already
non-dot-prefixed and already inside the bind-mounted workspace, which is the only placement
that satisfies both Finding 2's every-segment rule and Pattern 4's requirement that a result
path be translatable by `containerPath()`. `.vice-supervisor/` and `.planning/` are
disqualified as ancestors by Finding 2, at any depth.
