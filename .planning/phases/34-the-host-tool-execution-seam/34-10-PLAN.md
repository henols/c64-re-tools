## Two NEW recorded assumptions (no CONTEXT.md exists for this phase)

`/gsd-discuss-phase` never ran for Phase 34. Its design decisions live as fourteen recorded
planner assumptions `A-01`..`A-14` in `docs/phase34-host-tool-seam-decisions.md`. This plan adds
two, in that document's own convention, and both are NEW rather than inherited:

**`A-15` (NEW) — the walk is implemented LOCALLY in `host-tool.mts`, not imported from
`anno-types.ts`, and the anti-drift mechanism is an equivalence test rather than a shared symbol.**

The todo's stated preference — "export and reuse `realpathOfNearestExisting()` from
`anno-types.ts`" — is **architecturally blocked, and the block is structural rather than a
preference**:

- `anno-types.ts` is a container-side `.ts` module. `host-tool.mts` is host-bound: `build.ts`
  compiles it into the committed `src/mcp/vice/resources/host-tool.mjs`, which runs on a bare host
  Node with no type-stripping, and `build.ts` asserts the emitted file set exactly matches the ten
  `HOST_BOUND_ARTIFACTS` entries.
- Every `.mts` in this package imports only `node:*` builtins and sibling compiled `.mjs`.
  `host-tool.mts`'s single local import is `./ghidra-project.mjs`, a VALUE import of a sibling
  host-bound artifact (that is `A-06`'s whole subject). An `import … from "./anno-types.ts"` would
  not survive compilation into `resources/host-tool.mjs` — and `anno-types.ts` transitively imports
  `./vice.ts` and `./disasm-opcodes.ts`, neither of which is host-bound either, so the block is not
  removed by compiling one more file.

So the walk is duplicated **deliberately**, and the price of the duplication is paid explicitly:
Task 2 adds a test that drives BOTH implementations over one fixture table and asserts they agree.
That is this project's established deliberate-duplication-plus-equivalence-assertion shape — the
same one `34-09` used for the two per-tool timeout tables, and the same discipline
`anno-types.ts:1226-1227` already names for its own two consumers of the walk ("the two must not
drift apart"). The equivalence test compares the two PUBLIC seams rather than a shared private
symbol, so no export is added to `anno-types.ts` and nothing about that module's surface changes.

*Reversibility: costly.* If a future phase makes `anno-types.ts`'s walk reachable from a host-bound
module (by extracting it into its own host-bound sibling artifact), collapsing the duplication means
touching `build.ts`'s `HOST_BOUND_ARTIFACTS`, `tsconfig.build.json`'s `include[]`, both consumers
and the equivalence test in one commit — a coordinated change, not a one-line edit.

**`A-16` (NEW) — the seam returns the REAL path, and the container-translation consequence is a
recorded limit rather than a widened `hostpath.ts` consumer set.**

`34-VERIFICATION.md`'s gap 3 requires the real path as the `ok: true` result, and it is the only
honest answer: the returned path is exactly what gets spawned, so returning the lexical join while
confining on the realpath would hand the caller a string the filesystem then reinterprets. The
consequence is that on a host whose workspace root is itself reached through a symlink, the response
`path` is now the root's real location, which need not match any member of `hostRootCandidates()`
(`containerpath.ts:88`) — and `containerPath()` THROWS rather than passing an untranslatable path
through (`containerpath.ts:151-157`). The pre-existing mitigation is the `HOST_WORKSPACE_PATH`
environment variable naming the real root; the fix is NOT to add a realpath to
`hostRootCandidates()`, because `hostpath-consumers.test.ts`'s own header states that widening its
five-member consumer set is a REVIEWED DECISION and not a mechanical repair. This plan records the
limit at the seam and in `A-16`; it does not touch `hostpath.ts` or `containerpath.ts`.

*Reversibility: costly.* See Task 1's reversibility rating.
