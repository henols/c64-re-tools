<objective>
Act on `13-PROBE-RESULTS.md`: remove each confirmed assumption's `[ASSUMED]`
label at every site that carries it, correct and regression-test each
contradicted one, leave each inconclusive one alone, and add a committed guard
that makes a half-stripped label impossible to land silently.

Purpose: the correction unit is the label, not the file — and the label lives at
several sites for A2 and A3, so the naive "one file to correct" reading its todo
gives is measurably wrong. Stripping one site and leaving its twin still claiming
the detail unverified would put contradictory statements in shipped source.

Output: consistent labels across the whole authored source tree, regression tests
for any corrected behaviour, updated Assumptions Log rows, and a permanent
all-or-nothing label guard.
</objective>
