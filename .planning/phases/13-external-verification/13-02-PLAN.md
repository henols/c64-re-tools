Commit both real `--help` transcripts, prove the backend discriminator against
both real builds end to end, and pin the result with a fixture-driven regression
test built from the real strings and kept separate from the author-constructed
fixtures already in the file.

a real VICE binary. Every existing test in `backend-detect.test.ts` drives them
against author-constructed strings explicitly labelled as guesses, and
`docs/phase2-backend-probe-evidence.md` §2 records the question as OPEN. Both
binaries are present on this host, so this is a commit-the-evidence job, not a
discovery job — but committing the evidence is what stops the classifier drifting
away from what real builds print.

Output: two verbatim transcripts plus sidecars in a new
`fixtures/backend-detect/` directory, a real-hardware test block, and an evidence
document recording the `probeBackend()` and `resolvedBackend()` runs.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host shell → each `x64sc` binary | which path is spawned decides which build the transcript is evidence of |
| `x64sc` stdout+stderr → committed `.txt` fixture | untrusted process output becomes a committed artifact and a test input |
