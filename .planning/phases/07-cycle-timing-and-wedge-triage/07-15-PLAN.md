<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| binary monitor socket -> `gatherStockCheckpointTrapEvidence()` / `runStockLivenessBracket()` | Untrusted wire input during diagnosis; a decode failure mid-diagnosis must not be reported as a healthy state |
| the diagnosis answer -> an agent's decision to call `vice_recycle` | `vice_recycle` is destructive and irreversible for the running instance; a misleading diagnosis directly causes data loss of the in-flight run |
| environment variables (`VICE_STOCK_DIAGNOSE_SESSION_TIMEOUT_MS`, `VICE_STOCK_DIAGNOSE_BRACKET_MS`) | Operator-controlled bounds on the diagnosis |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-15-01 | Spoofing | `machinePaused` evidence field | mitigate | Task 1 derives it from `runStateFor()` at one place and labels inferences `"structural"`, so a paused machine can never be reported as running by a stale literal. |
| T-07-15-02 | Elevation of Privilege | escalation to `vice_recycle` on an unestablished diagnosis | mitigate | Task 2 requires every `diagnosis_unavailable` message to state the machine state is unknown and that recycling on this answer alone is wrong; Task 3 pins that wording with a regex assertion. |
| T-07-15-03 | Repudiation | opaque `session acquisition failed` text | mitigate | Replaced by a classified outcome with a stable, greppable prefix, so an incident record can name the failure class rather than quoting a protocol string. |
| T-07-15-04 | Denial of Service | unclassified error looping or hanging the diagnostician | accept | The existing `Promise.race` bound (default 10000ms, D-03 discretion) is unchanged and already bounds acquisition; this plan only changes how the bounded failure is reported. |
| T-07-15-05 | Tampering | the frozen verdict set | mitigate | Task 3's guard case asserts exactly five members in D-03's order and rejects both `stale_read_path` and `diagnosis_unavailable`, so the locked decision cannot be widened silently. |
| T-07-15-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs; no new dependency permitted. |
