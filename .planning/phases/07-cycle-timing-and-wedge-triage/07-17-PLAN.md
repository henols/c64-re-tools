## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| spawned emulator's binary monitor port -> test process | Unauthenticated full machine control; binding scope is a real security property |
| `VICE_LIVE_TRIAGE_BIN` -> `spawn()` | Operator-supplied executable path, passed as argv, never through a shell |
| test-written epoch file -> `readEpoch()` | The test is deliberately forging a state-change signal; it must do so only inside its own scratch directory |
| `-jamaction` and `vice_registers_set`/`vice_memory_write` -> the emulated machine | The test intentionally corrupts the emulated CPU state |
