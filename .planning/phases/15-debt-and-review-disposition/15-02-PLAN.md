<objective>
Close six of Phase 08's ten open review findings — the ones that live in the two
CI-gating skill-lint scripts — by applying each finding's own written fix from
`08-REVIEW.md`, and extract the duplicated corpus-traversal seam those two scripts share.

Purpose: `WR-12` is the load-bearing one. `check-skill-fork-honesty.mjs:73`'s own comment
admits it copied `walkSkills()` from `check-skill-tool-coverage.mjs`; both are blocking CI
steps whose entire purpose is to agree about which skill text exists and which tool names
it contains, and the failure mode of divergence is one gate passing while the other should
have failed. That is CLAUDE.md's named "re-deriving a cross-cutting seam locally"
anti-pattern, committed in the very phase that consolidated capability data to avoid it.
`WR-06`, `WR-07`, `WR-09`, `WR-10` and `WR-11` are all guard-quality defects in the same
two files — vacuous assertions, an accidentally-widened allowlist, a line-wrap-dependent
lint, a section-scoped rule that should be tool-scoped, and error messages pointing at the
wrong line.

Output: `scripts/lib/skill-corpus.mjs`, both scripts importing it, and five substantive
guard-quality fixes with the disposition citation each finding needs for GATE-02.
</objective>
