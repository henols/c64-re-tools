<objective>
Four Phase 10 findings that share one property: each is a surface a reader trusts, telling them
something that is not true — plus the one Info finding that can silently swallow the diagnostic a
user most needs.

**WR-11 (confirmed still live):** `acme.mjs:238`'s own `--help` reads
`scaffold a C64 program (BASIC stub + libs)` for a scaffold plan 10-07 deliberately made
library-free. `SKILL.md` was updated; the driver's usage block was not. This is the same
documentation-honesty class this milestone built a CI guard for, on the surface most likely to be
read first.

**IN-05:** `acme-build/SKILL.md:155-156` reads "The scaffold `new` writes / assembles against a bare
install" — a word is missing.

**IN-03:** `check-skill-fork-honesty.mjs:386`'s `\bdisasm\b` matches `disasm-decoder.ts`, because `-`
is a non-word character. Any future skill doc that legitimately names the stock live-RAM
disassembler's Phase 4 modules fails CI with a message about a deleted `toacme` verb — and a pin
that false-positives is a pin that gets switched off.

**IN-01:** `vice-proxy.ts:224-227` ends the process the instant `runR2000Cli()` resolves. On a pipe,
`console.log`/`console.error` writes are asynchronous and `process.exit()` discards what has not
drained — verified at 128 KiB truncation on this host's Node. The reachable trigger is
`cmdExportAsm`'s `console.error(result.stderr)`, which can carry up to `maxBuffer` of child output:
the one case where the user most needs the diagnostic is the one where a piped invocation can lose it.

Purpose: three of these are read-first surfaces and one is a data-loss path. None is expensive, and
each was left with no disposition anywhere (AUDIT-01, D-11.1-04).

Output: honest help text pinned by CI, a grammatical Setup sentence, a deletion pin that stops
false-positiving on protected module names, and a bounded drained exit — with CLAUDE.md's line
citations re-verified afterwards.
</objective>
