# Phase 11.1 Plan 03: Close INT-01 and Phase 10 IN-02 -- Self-Deriving the R2000-02 Absence Guard Summary

**Replaced hostpath-consumers.test.ts's stale 10-name r2000 array with a `readdirSync`-derived set (floor >= 14, positive control on the four uncovered modules), and widened its import detector from single-line-static-only to also catch multi-line named imports and `await import(...)`, with a committed planted-violation test for each widening -- both demonstrated failing under real, reverted edits.**

## Performance

- **Duration:** 45 min
- **Tasks:** 2/2
- **Files modified:** 1 (`.claude/mcp/vice/hostpath-consumers.test.ts`)

## Accomplishments

- **Task 1 (INT-01):** The r2000 module family the R2000-02 absence assertion checks is now `r2000ProductionModules()` -- `topLevelProductionModules()` (the pre-existing `readdirSync`-based helper the five-member `EXPECTED_IMPORTERS` test already used) filtered on `/^r2000-.*\.ts$/`. Added `R2000_MODULE_FLOOR = 14` (the measured true count) with an assertion the derived count clears it, and a positive-control test naming `r2000-acme-ident.ts`, `r2000-regbits-gen.ts`, `r2000-symbols.ts`, `r2000-test-gate.ts` by name so a future rename that drops one out of the glob says which one. Extracted the import-detection logic into a single named predicate, `importsHostpath()`, called by both the real scan and a new planted-violation test.
- **Task 2 (Phase 10 IN-02):** `HOSTPATH_IMPORT_RE` now matches against the whole comment-stripped source with the `m` flag instead of per-line -- `[^;]*` already spans newlines in a JS character class, so this alone makes a multi-line named import (`import {\n hostPath,\n} from "./hostpath.ts";`) detectable. Added `HOSTPATH_DYNAMIC_IMPORT_RE` alongside it (mirroring `check-npm-packages.mjs`'s own static+dynamic regex pairing, never a replacement) to catch `await import("./hostpath.ts")`. Extended `stripCommentLines()` to also strip `/* ... */` block comments, reusing `r2000-launch.test.ts`'s own WR-02-fixed, position-based implementation (closes on the first `*/` by index, not by whether the trimmed line ends with one) rather than writing a second comment stripper. Added a three-shape planted-violation test: multi-line static and dynamic imports are both detected; a source whose only "hostpath" mentions are inside a `//` comment and a string literal is not -- the control proving the widening did not degrade into a substring search.
- Both widenings were demonstrated failing under a real, reverted edit (not transcript-only claims): see Verification Evidence below.
