    Layout, taken from the committed captures rather than from prose: each entry line is a
    memspace marker of the form dot, a single memspace letter, colon, then a 4-hex-digit
    address; two spaces; one to three raw opcode bytes as space-separated pairs of hex
    digits, space-padded to a fixed column; the disassembled mnemonic and its optional
    operand as free text up to the register block; then the four labelled register fields in
    the fixed order A, X, Y, SP, each a 2-hex-digit value; then an 8-character
    processor-flag string; then a right-aligned decimal cycle count.

    Three closed sets, each refusing rather than guessing. First, the memspace letter: the
    only recognised value is the main CPU's `C`. Any other letter means the monitor's default
    memspace is pointed at a drive, at which point every field on the line describes a
    different CPU than the caller believes — refuse, and put the remedy in the message by
    naming the default-device reset tool (`vice_device_console`) rather than a bare
    complaint. Second, the processor-flag string: it is exactly 8 characters, and character
    at index i must be either a period (that flag clear) or the set-glyph for that position,
    where the set-glyph sequence is the fixed string `NV-BDIZC` — so index 2's set-glyph is
    literally a hyphen, the unused bit VICE prints that way. Anything else refuses with the
    unrecognised-flag code: a character silently treated as "clear" is an inverted statement
    about the machine's flags. Third, the register labels: exactly A, X, Y, SP, in that
    order; a different label or order refuses.

    Decode `flags` into a closed set — a readonly array (or a frozen record of booleans) over
    the named flags, with the unused position represented as its own member rather than
    folded into a neighbour. Parse `cycles` with an integer parse over a digits-only field
    and refuse on a non-digit; accept up to 12 digits, since VICE widened this column to a
    12-digit counter, and never assume a narrower width. Do not enforce monotonicity across
    entries: there is no monotonic cycle register on this backend, and asserting an ordering
    the emulator does not promise would turn a legitimate reading into a refusal.

    Framing: strip an optional trailing prompt of the shape `(C:$xxxx)` with trailing
    whitespace, anchored at the very end. Do NOT strip a leading prompt: `memmapshow` is the
    only command in the batch that emits an entry-echo, and stripping a first line here would
    delete a real history entry. A payload that is empty, whitespace-only, or consists solely
    of the trailing prompt refuses with the empty-response code — never an empty entries
    array, which would read as "the CPU executed nothing".

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| VICE text output → parser | Untrusted-in-shape input: a different VICE build, or a contaminated default memspace, may emit values these parsers have never seen |
| parser result → downstream evidence | A wrong flag set, a fabricated caller, or a wrong cycle count becomes evidence a reverse-engineering session acts on |

Note: neither module in this plan touches a socket, an argument from a caller, or a command
string. There is no new input-validation boundary here — the caller-argument boundary
arrives with the tools in plan 42-07 and the command parameterization in plan 42-04.
