<plan_decisions>
**D-42-3 is inherited, not re-decided.** Plan 42-01's `<plan_decisions>` block fixes the
refusal discipline for all five parsers: refuse by RETURNING a discriminated refusal, never
by throwing. Read that block and 42-01's `textmon-memmap.ts` before writing either module
here.

**The `io` parser's third answer, decided here.** `prof flat`, `chis`, `bt` and `memmapshow`
are closed formats: every field is either recognised or it is drift. `io`'s middle section
is not — it is free-form decoded prose whose line set differs per chip, and a parser that
refused every line it had not seen before would refuse a legitimate reply from a chip the
committed captures never sampled. So this module has three outcomes rather than two:
recognised fields decode to typed values; a recognised field whose VALUE cannot be parsed
refuses by name (that is drift, and it is loud); and a line matching no recognised shape at
all is preserved verbatim in an `unrecognisedLines` array that the result carries and the
tool reports as a count. Drift stays visible in the answer instead of being dropped from it,
and nothing unrecognised is ever mapped onto a typed field. This narrower rule applies to
`io`'s decoded-prose section only — its hex dump, its memspace marker and its sprite table
are closed sets and refuse like every other format.

**No `package.json` edit in this plan.** A module joins `files[]` in the same plan that makes
shipped code import it; plan 42-07 adds both of these modules when it wires their handlers.
</plan_decisions>

    implementation — split each row on a whitespace run — silently cuts every cycle count
