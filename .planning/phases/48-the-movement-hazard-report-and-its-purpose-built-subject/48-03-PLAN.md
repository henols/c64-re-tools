<objective>
Build the three remaining detectors on top of the proven slice — class 1 by importing the
scanner that already exists, class 3 and class 4 as genuinely new static analysis — and make
the report's honesty structural: a third undecided outcome that is reached by real fixtures,
a boolean verdict shape that a test refuses, and a limits list that names what each class
cannot determine.

Purpose: three of the four classes have no transferable prior art, and the fourth has a
shipped scanner that survived a real false-positive incident and must not be rebuilt. The
danger in the three new detectors is not that they miss things — it is that a miss gets
rendered as a guarantee. This plan puts the structure that prevents that in place at the same
time as the detectors themselves, so there is never a commit where a detector exists without
its limit.
Output: the completed detector set in `anno-hazard-report.ts`, the exact-count reuse test,
and the tests that refuse a boolean shape and prove the undecided outcome is reached.
</objective>

<assumption_delta_decision>
**Noun now primary:** the indexed-dispatch scan, `scanIndirectDispatch()` in
`src/mcp/vice/anno-coverage.ts`. Before this phase it had exactly ONE consumer, the coverage
report builder in its own module. This plan makes it a SHARED primitive with two.

**Decision: `no-change`.** The scanner stays exactly where it is, exported from
`anno-coverage.ts`, and the hazard report imports it.

**Rationale:** moving it would drag its closed shape list, its gate-route table and the four
source-text assertions that hold those two down against the module's own text — all hardened
after a real false-positive incident — across a module boundary for zero behavioural gain,
and every one of those assertions is written against that file's source text by name.

**What would later force a `promote`:** a third consumer, or the first consumer that needs
the scan without the coverage module's census and image-loading imports coming along with it.
Either is a real signal that the scan has outgrown its host; neither is true today.

**Direct consequence for the reuse test:** the non-test call-site count is now **2**, not 1.
The test asserts that exact number and its failure message names both sites — the coverage
report builder and the hazard report — and states that a third site means either a new caller
that must be recorded here, or a second implementation, which the phase forbids.
</assumption_delta_decision>
