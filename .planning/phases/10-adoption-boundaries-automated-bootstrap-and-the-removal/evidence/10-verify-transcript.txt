the process's own exit status. This is D-10 demonstrated in BOTH directions
on real, unedited output from this host, in the same evidence file:

    correct verdict is still ok:true, proving a non-zero exit must not
    produce a false NEGATIVE.

    case: exit 0, ACME never ran -- the correct verdict is ok:false, proving
    a zero exit must not produce a false POSITIVE.
