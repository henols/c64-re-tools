<objective>
Derive and execute the dxa, export-asm and petcat fixture families, and commit
their stores in the D-02 export form.

This is D-12's first half — the mechanical one. dxa gives the byte-derived
partition, Ghidra gives the cross-references, the live runs give the execution
evidence the gate requires as an input. No names and no purpose comments are
written here; the authored half is plan 45-08's job, and keeping them apart is
what makes D-03's split provenance real rather than declared.

Six fixtures: three executable (dxa/tracer.prg, dxa/fixture.prg,
export-asm/smc.prg), three declared non-executed (dxa/basic-stub.prg,
petcat/computed-sys.prg, petcat/not-basic.prg). The split is the manifest's,
fixed by RESEARCH.md §1, and is not re-derived here.

Purpose: the gate cannot measure a fixture that has no store, and it cannot
distinguish "clean" from "never looked at" without a real run identity to
anchor the disagreement query.

Output: six committed `.annostore.json` artifacts, three family README
provenance entries, and an evidence document recording every run.
</objective>

| Boundary | Description |
|----------|-------------|
| fixture bytes -> dxa and Ghidra (external tools) | Untrusted-shaped program bytes are handed to two external analysers |
| memmapshow text -> anno_evid_ingest | A parsed emulator reply becomes durable store rows |
| live emulator -> the host session | A running fixture can wedge, loop forever, or outlive the task |
| derived export -> the git tree | Generated content becomes a committed artifact |
