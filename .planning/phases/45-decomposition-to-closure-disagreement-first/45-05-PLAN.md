<objective>
Put the one decoder behind two renderers (D-16), and make the ACME export
carry criterion 5's proof (D-17).

The export is where the decomposition is PROVEN: `anno-export-asm.ts` already
sits under a real-ACME byte-diff oracle, so an arithmetically wrong split
either fails to assemble or fails the diff — nothing has to be trusted.
`anno_disassemble` is where the decomposition is READ: it is what a Claude
session actually looks at, and it currently ignores the store handle it
already requires.

Neither surface decodes anything itself. Both call
`decomposeRegisterValue()` from plan 45-03.

Purpose: criterion 5 asks for named enum members instead of magic numbers,
with at least one multi-bit register shown decomposed into its named bits.
D-17 settled that a bare hex constant with a comment still "emits one hex
constant", and bare constants with no comment are not readable — so both
halves are required and neither may be trimmed as over-engineering.

Output: the OR-ed render with its definition lines and refusals, a real-ACME
byte-diff test case proving it reassembles, and the same rendering in
`anno_disassemble`'s listing.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| store enum usage rows -> emitted ACME symbols | Store content becomes assembler source that must reassemble to the same bytes |
| generated term names -> ACME's single symbol namespace | Two generated names could collide |
| store comments -> rendered trailing comments | Authored text is merged with generated text on one line |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-45-18 | Tampering | An arithmetically wrong decomposition changing the assembled byte | high | mitigate | The real-ACME byte-diff oracle assembles the exported source and diffs against the source image; the non-vacuity assertion additionally requires the ` | ` form to be present so the diff cannot pass on a hex-literal regression |
| T-45-19 | Tampering | A symbol collision in ACME's single namespace silently redefining a constant | high | mitigate | The existing collision check is extended to cover per-field term names; a name defined twice with different values is refused by name with both values |
| T-45-20 | Repudiation | An authored side comment being dropped behind generated text | medium | mitigate | The merge renders the authored comment first and the mechanical decode after a ` -- ` separator; a test asserts both are present and ordered |
| T-45-21 | Tampering | A refusal replaced by a silent fallback to the hex literal while still counting a substitution | high | mitigate | The decoder's throw propagates with the address prepended; the file's own recorded past defect (counting a substitution that did not happen) is named in the code comment so the fallback is not reintroduced |
