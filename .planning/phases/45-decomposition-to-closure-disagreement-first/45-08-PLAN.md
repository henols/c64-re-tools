<objective>
Walk the dxa, export-asm and petcat family to closure: names, purpose
comments, resolved symbols, recorded declines and installed enums, until the
completeness gate exits 0 for all six fixtures.

This is D-12's second half — the part derivation cannot do. The stores from
plan 45-06 carry every byte typed, every cross-reference imported and zero
names. Everything this plan writes is AUTHORED content, tagged as such, and
frozen once reviewed (D-03).

The queue comes from cross-references and block classification, not from a
label-prefix scan: RESEARCH.md §2 MEASURED that these stores carry no labels
at all, so the legacy scan would report an empty queue on a fixture where
nothing has been named. Plan 45-04 already taught the skill playbook that;
this plan is the first real use of it.

Purpose: criteria 3 and 4 are per-entry-point and per-address obligations. An
aggregate count cannot discharge them, and the gate is written so it cannot be
satisfied by one.

Output: six closed stores, an evidence document naming what was declined and
why, and a gate that exits 0 for each.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent-authored names and comments -> the committed artifact | Free-text judgement becomes a durable, reviewed record |
| join declines -> persisted comments | An ephemeral tool response becomes the durable decline record |
| the gate's exit code -> "this fixture is done" | A process exit code terminates human judgement |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-45-32 | Spoofing | A confident wrong symbol at an address whose target genuinely varies | high | mitigate | export-asm/smc.prg's self-modified operand is declined by name with the variance stated; the gate accepts a decline and rejects silence, so "left alone" cannot pass |
| T-45-33 | Repudiation | A purpose comment that looks complete but names none of the four elements | high | mitigate | The gate checks the four labels per entry point and exits non-zero naming the address; semantic truth stays a human review, recorded per entry point in the evidence document |
| T-45-34 | Tampering | A second label silently overwriting an existing one | medium | mitigate | A verify asserts one label row per address in every store; refused writes are replayed rather than forced |
| T-45-35 | Repudiation | A decline recorded only in a tool response and lost when it returns | high | mitigate | Every decline is persisted as a store comment with the single declared prefix, and the evidence document's text must match the store's |
