<plan_decision_D-05-06>
**A session-free derived answer needs `runState` too, so `derivedAnswer()` joins
`stock-handler.ts`.**

`stock-dispatch.test.ts` carries a standing gate — *"every stock entry's outputSchema
declares a required runState enum of [running, stopped, unknown]"* — that walks **every**
entry in `tools-manifest.stock.json` with no exemption list. `vice_symbols_load` and
`vice_symbols_lookup` are the only `needsSession: false` tools in the milestone: they
receive no `session`, so they structurally cannot call `stockAnswer(session.client, ...)`,
which is the ONE place `runState` is stamped.

Three options were considered:
1. Hand-build a `{ content, isError: false }` literal in `stock-symbols.ts` with no
   `runState`, and add the two tools to a new exemption set in the D-06 gate.
   **Rejected** — it weakens a standing gate for two tools and reintroduces exactly the
   failure `stock-handler.ts`'s own header warns about ("never build a
   `{ content, isError: false }` literal outside `stockAnswer()` — that is exactly how
   an answer ships without `runState`").
2. Give the symbol tools a session so they can use `stockAnswer()`. **Rejected** —
   D-04 of Phase 4 created `needsSession: false` precisely because every touch of the
   wire halts the machine (Phase 3 D-05); loading a label file must not stop the user's
   running program.
3. **Chosen: add `derivedAnswer(payload)` to `stock-handler.ts`** — the ONE place a
   session-free derived answer is constructed, stamping `runState: "unknown"`. This is
   the honest value, not a placeholder: no session was opened, so the emulator's run
   state was genuinely not observed, and `unknown` is already documented as
   "the honest post-connect value and is not a failure"
   (`docs/stock-vice-parity.md` §A.7). The standing gate needs no change, both symbol
   tools declare `runState` in their `outputSchema` like every other entry, and the
   conformance harness treats them uniformly.

This is an addition to the existing seam, **not a third error converter and not a
second answer builder for sessioned tools** — `stockAnswer()` remains the only path
for anything holding a session.
</plan_decision_D-05-06>

<plan_decision_D-05-02>
**`format: 'kickasm'` and `format: 'simple'` are refused by name; `'auto'` and
`'vice'` parse the confirmed `al C:xxxx .Name` pattern only.**

No skill or script in this repo produces a KickAssembler label file or names a
"simple" format anywhere. The two named producers are ACME (`--vicelabels`, confirmed
byte-for-byte against `acme-build/scripts/acme.mjs`'s own parser regex) and
regenerator2000 (`--export_lbl`, whose exact output is **unverified** — `R2000-16(c)`
has not been run).

Refusing by name is chosen over silent non-support because a KickAssembler file fed to
the VICE parser yields "0 symbols loaded" with no explanation of why. `'auto'` does
**no format sniffing** — it parses the `al C:xxxx .Name` pattern and reports the count
actually loaded; a 0-symbol load is itself diagnostic and is a **success with an
explanatory note**, never an error.

**Do not claim regenerator2000 compatibility as a fact.** The parser is written
defensively (any non-matching line is skipped and counted, never a whole-file
refusal), and the module header records this as a stated assumption for `R2000-16(c)`
to confirm or contradict later.
</plan_decision_D-05-02>

**`SymbolTable` interface:** `{ byName: Map<string, number>; byAddress: Map<number, string>; }`.

**`resolveLabelFilePath(pathArg: unknown): string`** — the containment control:
1. Refuse a non-string, or an empty/whitespace-only string, by name and `typeof`.
2. `const root = repoRoot();` then `const resolved = resolve(root, pathArg.trim())` —
   a relative path resolves inside the workspace; an absolute path resolves to itself
   and is then checked.
3. Refuse unless `resolved === root || resolved.startsWith(root + sep)`. The refusal
   text names both the resolved path and the workspace root and states that a symbol
   file must live inside the workspace.
4. **Symlink check:** `realpathSync(resolved)` and re-apply the same containment test
   to the real path, so a symlink *inside* the workspace pointing outside it is refused
   too. An `ENOENT` from `realpathSync` is reported as "file not found", distinct from
   an escape refusal.
5. Return the contained absolute container path. Never call `hostpath.ts`.

**`parseViceLabelFile(text: string)`** returning
`{ table: SymbolTable; symbolCount: number; skippedLines: number; duplicateNames: number; lineCount: number }`:
- Split on `\n`. Refuse (throw `StockSymbolsError`) when `lineCount > MAX_LABEL_FILE_LINES`,
  naming both the count and the ceiling.
- Per line: trim, skip empty lines and any line not matching `VICE_LABEL_LINE_RE`,
  incrementing `skippedLines`. **Never refuse the whole file on an unrecognised line.**
- On a match: `address = parseInt(group1, 16)`. A value outside `0..0xffff` is
  impossible given the `{1,4}` hex bound, but assert it defensively and count such a
  line as skipped rather than throwing.
- `byName.set(name, address)` — **last definition wins**, and increment `duplicateNames`
  when the name was already present.
- `byAddress.set(address, name)` only when the address is not already mapped — **first
  name for an address wins**, so the canonical name is the first one the file declares.
- Refuse when `byName.size > MAX_SYMBOLS`, naming the count and the ceiling.
