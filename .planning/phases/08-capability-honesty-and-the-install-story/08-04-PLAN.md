## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `.claude/skills/**` file content -> `check-skill-fork-honesty.mjs` | Skill files are untrusted input: they are walked, read and regex-matched, never executed |
| playbook prose -> Claude's next tool call | A playbook is a prompt: prose that names a tool the active backend lacks directly causes a failed call and a wrong recovery attempt |
| the four annotated sites -> a stock user's input strategy | Naming a stock route that does not work (e.g. implying buffer injection reaches a matrix-polling program) is worse than naming none |
