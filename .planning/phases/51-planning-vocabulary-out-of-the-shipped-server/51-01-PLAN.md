none of them may ever guess or copy a number from a planning document. With

freeze time. Exclude generated `resources/*.mjs` files from this array — they are
rewritten wholesale by the build, so a byte delta there measures the compiler,
not an author. Exclude non-source extensions, where the extractor finds no spans
and the check is vacuous.

file content: `entry.commentBytes - commentByteTotal(now)` must be less than or

file whose long explanatory header was cut to a one-liner fails immediately. Its
failure message must name the file, both baseline numbers, both current numbers,
the two deltas, and the standing rule: the reason survives, only the citation
goes.
