<objective>
Resolve, once and centrally, what the recurring citations in the shipped tree
actually meant — so that fourteen sweep plans consume one index instead of each
repeating the same lookups — and mint this phase's requirement ids.

Purpose: the phase's real risk is not the mechanical edit, it is an executor who
cannot recover what a citation MEANT and quietly deletes the comment instead of
replacing it. Lookup effort is the phase's scarce resource. This plan spends it
once.

Output: one evidence document consumed by every later plan in this phase, and
six requirement ids with traceability.

This plan touches no source file and no roadmap or state file. It runs in
parallel with plan 51-01.

Locked decisions implemented by this plan:

- D-07: recovery is tiered by identifier class, so lookup effort is spent where the ambiguity actually is.
- D-08: where nothing recovers a reason, the comment is rewritten to a weaker but true statement and the site is named in the plan's summary, never deleted.

Those identifiers belong to this planning document. No replacement string this
plan writes into product source may contain one.
</objective>

**Section B — the tier partition, in its corrected form.** Publish the ladder as
five tiers and state plainly that this REPARTITIONS membership inside the locked
tier structure rather than replacing it:

  - Tier 0, cheapest: a `Plan NN-MM` or `Phase NN` citation. A filename search
    under `.planning/phases/` resolves it directly to a plan or summary document
    whose own prose can usually be quoted or paraphrased. No history walk.
  - Tier 1: a bare parenthetical sitting beside prose that already states the
    reason. Drop the parenthetical and stop. Measured at roughly 43% of all sites.
    This is the largest class and needs no lookup at all.
  - Tier 2: a genuinely global id — a real requirement id, declared exactly once
    in the requirements document or its milestone archive, and a gap id, whose
    literal form embeds its own originating phase number. One search each.

    review and summary documents. Check the SUMMARY as well as the review: the
    fullest explanation of a review finding usually lives in the plan that FIXED
    it, which says what was actually done and why, rather than in the review that
    states the finding tersely.
  - Tier 4, the bottom: nothing recoverable. Rewrite the comment to a weaker but
    TRUE statement and name the site in the owning plan's summary. Never delete
    the comment.

State the correction explicitly and visibly: decision ids were originally placed
in tier 2 on the premise that they are globally unique. Measurement contradicts
that premise, so they sit in tier 3 with the review-finding ids. Gap ids and real
requirement ids stay in tier 2 and are genuinely cheap there.
