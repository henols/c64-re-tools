<objective>
Sweep the annotation export path and seven sibling modules — about 292 citations
across `anno-export-asm.ts`, `anno-register.ts`, `anno-memmap-render.ts`,
`anno-import.ts`, `anno-graphics.ts`, `anno-regbits-gen.ts`,
`anno-provenance-ledger.ts` and `anno-hazard-report.ts` — to zero.

Purpose: the export path is where this project's governing constraint is written
down in prose. Everything else in this plan is ordinary sweep work.

Output: eight files at zero, eight ratchet entries deleted.

Counts are sizing context measured before planning; the ledger is the authority.

**One file in this plan needs a binary-tolerant search.**
`src/mcp/vice/anno-memmap-render.ts` contains a NUL byte. An ordinary text search
treats it as binary and SKIPS it without saying so — that has already produced one
wrong decision in this project. Every search you run against it, and every search
in this plan's acceptance criteria, carries the flag that forces text treatment.

Locked decisions implemented by this plan:

- D-06: sweep plans partition by module family, not by file and not by citation category.
- D-07: recovery is tiered by identifier class, so lookup effort is spent where the ambiguity actually is.
- D-08: where nothing recovers a reason, the comment is rewritten to a weaker but true statement and the site is named in the plan's summary, never deleted.

Those identifiers belong to this planning document. No replacement string this
plan writes into product source may contain one.
</objective>
