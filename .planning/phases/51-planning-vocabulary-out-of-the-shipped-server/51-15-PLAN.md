<objective>
Sweep the text-monitor parsers and the disassembly and memory-map modules — about
152 citations across nine files — to zero.

Purpose: these modules turn one text format each into structured data. Their
comments record which output format was observed, on which build, and where the
format is known to drift. That is reference material, and the citations attached
to it are almost all bare parentheticals.

Output: nine files at zero, nine ratchet entries deleted.

Counts are sizing context measured before planning; the ledger is the authority.

Locked decisions implemented by this plan:

- D-06: sweep plans partition by module family, not by file and not by citation category.
- D-07: recovery is tiered by identifier class, so lookup effort is spent where the ambiguity actually is.
- D-08: where nothing recovers a reason, the comment is rewritten to a weaker but true statement and the site is named in the plan's summary, never deleted.

Those identifiers belong to this planning document. No replacement string this
plan writes into product source may contain one.
</objective>
