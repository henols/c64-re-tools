### 3b. Flat 64K raw import -- the split route

Synthetic 65536-byte image, sha256
d60f4994592d98235b20638996144125646bfeed87af16b17276983e153073c5, with the
processor port planted at offset 0 ($2F $37) and a 17-byte instruction run at
$4000 that writes $D020 twice with a read-modify-write of $01 after it -- the
exact shape dead-store elimination eats when volatility is wrong.

Note the two `Failed to add language defined memory block due to conflict` lines
for ZERO_PAGE and STACK near the top of the log. They are INFO lines, not errors:
the 6502 language wants to create those blocks and the flat image already
occupies $0000-$01FF. They are named here explicitly so a later plan that greps
its run log for a failure keyword does not misread them as a failed run. They
appear in the flat-64K route only; run 3c below, being a .prg at $0801, does not
produce them.
