<objective>
Test Ghidra's indirect-dispatch resolution where the dispatch index is **computed**, against
a site the emulator — not Ghidra — identified as computed, and record the result whichever
way it comes out.

Purpose: the pivot fixture used an immediate `ldx #$02`, which is the easy case, and
silently re-testing the easy case would reproduce exactly the defect this phase exists to
remove. The circularity trap is equally real: if Ghidra found the dispatch site, the
criterion degrades to "Ghidra resolved the dispatch that Ghidra found". D-06 closes it by
making the site list a runtime observation, and this plan checks that list against the
export rather than the other way round.

This plan is a vertical slice of criterion 2: import → carve volatile blocks → seed
observed entry points → analyse → export uncapped → check each observed site → emit the
outcome.

Output: `C2_COMPUTED_DISPATCH` — rule R6's only input — with its target or its transcript.
</objective>
