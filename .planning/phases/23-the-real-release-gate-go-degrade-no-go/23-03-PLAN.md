<objective>
Secure the corpus and turn it into the substrate every later measurement reads: two
independently-cracked releases of one title, each autostarted in VICE, run past its
loader/depacker, broken at the handoff, and captured as a verified flat 64K image.

Purpose: D-03 makes the depacked capture the substrate for criteria 1, 2 and 3 — a packed
payload is high-entropy bytes, so a data-recovery percentage taken on the shipped file
measures the packer's output rather than game code. D-02 makes VICE the route to the code of interest,
so the release is autostarted and navigated rather than statically unpacked. D-04 makes the
corpus operator-supplied and identified by hash so the numbers stay auditable without the image entering the
repository. This plan is a vertical slice: intake → boot → depack → capture → prove
equivalence → emit the gate input.

Output: two capture records, a scratch release registry, and `C0_CORPUS` — rule R1's only
input.
</objective>
