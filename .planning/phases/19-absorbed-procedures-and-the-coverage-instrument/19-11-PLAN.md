## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a `.regen2000proj` file → the dispatch scan | Payload content and the declared origin/length are attacker-controllable in the general case. Byte content must never promote itself to a proven entry point, and a table walk must be bounded by evidence rather than by arithmetic over two base addresses. |
| the class-4 scan → `provenDispatchTargets()` | The declared single seam. Before this plan, one of its four sources satisfied none of the conditions the other gated source must satisfy. |
| a heuristic's positive control → the claim that it declines anything | A scan with a positive control and no negative one is an unverified claim, which is the root cause this whole gap-closure run exists to close. |
