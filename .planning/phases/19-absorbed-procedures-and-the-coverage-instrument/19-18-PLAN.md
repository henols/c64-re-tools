<objective>
Close the hole in the anti-regression mechanism itself. Round 3's headline deliverable was a
mechanism that reds the suite BY NAME when a sufficient shape is admitted without an interior
negative control — and it passed over the defect it was built for, because
`reachesGateInterior()` defined one shape's interior as a DISJUNCTION of two routes and every
control declared against that shape satisfied only the class-4 half. The knowledge was already in
the source comment: that shape is "ruled on by TWO gates, not one". Nothing forced a control for the
second gate.

Purpose: re-key the identity of a control target from *shape* to *(shape, route)*, drop the
disjunction, and derive the route set from the module's own source text so a third consumer reds the
suite rather than silently creating an uncontrolled route (D-04, D-05). Then watch each of the four
new gates fail (D-07.1).

Output: `DISPATCH_GATE_ROUTES` and `PROVEN_TARGET_SOURCES` exported from `r2000-coverage.ts`; a
route-keyed declaration table; a four-argument witness with per-route predicates; a reachability
matrix over the full cross product; four source-derived pins; four planted-violation records.

**The route identity decision, stated once and for the record.** `route` is a CLOSED enumeration
DERIVED FROM SOURCE. `DISPATCH_GATE_ROUTES` is a frozen exported array in `r2000-coverage.ts` whose
membership is pinned to that module's own text; a declaration carrying a route outside it fails by
name; and `reachesGateInterior()` throws on a route it has no predicate for, exactly as it already
throws on an unknown shape id. It is deliberately NOT an open string: an open string is how the same
defect would return a fourth time, because a typo or a newly invented route name would create a
control target nothing checks.

**Requirement scope.** `ABS-01`…`ABS-04` and `SURF-03` are closed by plans 19-01…19-05 and are out of
scope for this round. `COV-02` is cited because the dispatch gate is the mechanism both requirements
read. The open requirement is `COV-01`.
</objective>
