image, with the sibling figure disagreeing sixteen-fold.

an instruction": the linear sweep skips illegal opcodes, `isPlausibleEntryPoint()` rejects them, and
the recursive descent — the third consumer — never tests the flag at all. Two standards, three readers.
The fix is one predicate with three consumers, exactly as `isPlausibleEntryPoint()` itself was extracted
when the two halves of `provenDispatchTargets()` were found held to different standards.

census's three readers are brought to ONE predicate, and that predicate is the one the linear sweep and

THE EVIDENCE: the measured contradiction — four code bytes followed by sixty `$02` bytes reporting

it.

includes stable undocumented instructions real C64 code does use — this repository carries its own
notes on them. A program that legitimately executes one will now have its census stop there and
under-report. The direction of the error is the safe one and it is no longer silent: the two figures
agree instead of contradicting each other, and the sweep already behaved this way, so the fix makes the
census share an existing limitation rather than inventing one. State the exact count of illegal-flagged
