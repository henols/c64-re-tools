<objective>
Close the first half of GAP 2 (SC4 / COV-02): make the multi-caller cross-reference rule
un-gameable by a colliding hex string, and prove it with the adversarial control that was
missing.

Purpose: the phase goal's own qualifier is "a coverage instrument … that **resists being
gamed**". Right now it does not. Taking the NC4 negative control **exactly as committed** — the
fixture whose stated purpose is "the two-caller label at `$0820` is documented without naming
either caller" — and appending a mention of `$8106`, an unrelated and entirely ordinary C64
address, to its comment flips the report from `{count: 1, addresses: [2080]}` and a non-clean
verdict to `{count: 0, addresses: []}` and a **fully clean verdict with zero findings**. The
comment still names neither caller. That is a falsely-clean verdict on the one measure whose
whole subject is refusing to be talked into a clean verdict. Phase 20 (*Decomposition to
Closure*) consumes exactly these numbers, which is what makes this blocking rather than
cosmetic.

This is the TRACER slice for the gap-closure run: the narrowest end-to-end proof that a gaming
attempt now fails, run through the real report path (`buildCoverageReport` →
`coverageFindings`) against the real committed fixture — a reproduction that goes from red to
green on the actual instrument, not a unit assertion in isolation. It is production-quality,
not a probe: no stub, no follow-up required to make it real.

Output: an anchored `namesACaller()`, dedup-derived counts, and three new controls in
`r2000-coverage.test.ts` that fail against the current code and pass after the fix.
</objective>
