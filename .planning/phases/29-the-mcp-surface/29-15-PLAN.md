| Boundary | Description |
|----------|-------------|
| shipped playbook prose → an agent's Bash invocation | The playbook is the instruction an agent follows literally; a documented command is executed, not read |
| canonical skill tree → generated installer tree | A one-way generation boundary; the shipped artifact is derived and must never become a second source |
| copy-forward template → every new project | The template propagates whatever it says into projects this repo will never see again |
