## Decisions and readings adopted by this plan

- **Discretion 1, adopted with research's corrected measurements.** The scope
  predicate is `( git ls-files , minus the .planning/ prefix ) ∪ packFiles("installer")`.
  The blast radius is **339** tracked files mentioning the subject and **61**
  outside `.planning/` — not the 291 / 55 in `29-CONTEXT.md` and `CUT-02`, which
  are superseded. Of the 61, roughly 18 legitimately keep the word forever, so a
  whole-tree-minus-planning gate is viable; this is the opposite of what `CUT-02`'s
  framing implies, and the corrected figure is what the gate is built against.
- **The `installer/skills/` hole is structural, not hypothetical.**
  `git ls-files installer/skills` returns 0 while 8 files there mentioning the
  subject **are shipped** (`@henols/c64-re-tools`, 34 files, 7 skills). A tracked-files
  predicate is blind to exactly what users receive, which is why the union with
  `packFiles` is not optional. `npm pack --dry-run` runs `prepack`, which runs
  `sync-skills.mjs`, so the file list is post-sync **by construction** — a
  "remember to sync first" predicate can forget; this one cannot.
- **False negative B is accepted and stated rather than discovered:** an
  untracked, not-yet-`git add`ed file is invisible to a `--cached` predicate. CI
  runs post-commit, so the window is local-only. This is a recorded tradeoff.
- **`29-PATTERNS.md`'s finding on exemption ordering is load-bearing:** in
  `check-skill-fork-honesty.mjs` the unconditional checks run **before** the
  exemption is consulted (WR-03 was a line whose exemption substring
  short-circuited all three checks), and the exemption is line/block-scoped and
  shape-matched with an exact hit count — never a substring.
