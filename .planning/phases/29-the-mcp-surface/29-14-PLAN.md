<objective>
Close verification gap 3 — the reproduced confinement escape on the `anno` CLI's
caller-supplied paths, and the three headers that assert in writing the property
the code does not keep.

Reproduced on this working tree by the verifier, on arguments that are
LLM-composed by design (the shipped playbooks invoke this CLI through Bash):

- **`--out` on `render-memmap` escaped the workspace root entirely and silently
  overwrote a pre-existing file.** `--force` is not in that verb's option set at
  all, and the verb never reaches `refuseOverwrite()`.
- **`--provenance` is an arbitrary-file-read oracle with content disclosure.**
  Pointed at a file outside the repo, it echoed that file's opening bytes back
  in the error message, because the sidecar parse failure interpolates Node's
  own parse error and that error carries a content snippet.
- **`--out` on `coverage`** takes the same escape: it is checked for overwrite
  and then written, both against the raw caller string.

The seam itself is excellent — fifteen thorough tests of
`storePathWithinWorkspace()` — and its CONSUMER SET is unenumerated. That
asymmetry is the whole mechanism of the failure, and it is the thing worth
fixing rather than the four call sites alone. `hostpath-consumers.test.ts` does
exactly this for the host-path seam and is the model.

Purpose: this is a violation of CLAUDE.md's standing architectural constraint
that any host-facing or caller-supplied path goes through one confinement seam,
on the delivery path REPOINT-01's absorbed procedures are documented to invoke.
Output: both verbs confined on every argument, `--force` where the safety check
needs it, a closed-consumer-set test, and three headers that tell the truth.

**Scope note.** The confinement used here is `storePathWithinWorkspace()` from
`anno-types.ts` — the annotation family's OWN seam. Do NOT reach for
`hostpath.ts`: no `anno-*` module imports it, that absence is asserted
structurally by `hostpath-consumers.test.ts` and by a body-slice assertion in
`stock-dispatch.test.ts`, and it is how MCP-02 is satisfied by construction.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent-composed Bash invocation → `anno` CLI arguments | Untrusted, LLM-composed path strings cross into `readFileSync` and `writeFileSync`. The shipped playbooks tell the agent to compose these; this is the designed route, not an abuse of one. |
| workspace root → the host filesystem | The confinement seam is the only thing standing between a mistyped or manipulated argument and any file the process can reach |
| CLI error text → the agent's context | Bytes interpolated into a refusal become readable by whatever composed the invocation |
