<objective>
Disarm the generator behind the gap plan 52-11 just closed.

`CLAUDE.md`'s Technology Stack, Conventions and Architecture sections are not
hand-written. They sit inside marker blocks whose own comments name their source:
`codebase/STACK.md`, `CONVENTIONS.md`, `ARCHITECTURE.md`. All three of those
source documents are dated 2026-09-01 — eleven days before this phase removed the
fork backend — and all three still describe it as a live, selectable backend, in
far more detail than `CLAUDE.md` itself did. The architecture document alone
carries roughly thirty such lines, including a system-overview diagram with a
per-backend branch and a whole data-flow section for the removed transport.

This is the failure mode this repository has already met once and already wrote a
guard for. `docs-constraints-sync.test.ts`'s own header records it exactly: the
stale copy was the one the marker named as the source, *"so regenerating the block
would have pushed the stale text back OVER the corrected text"*. That guard covers
one bullet list. Nothing covers these three documents, and a guard cannot be
pointed at them — they live in the planning tree, which legitimately quotes every
removed name while recording the removal.

So the remedy is the same one the `## Constraints` pair got: reconcile both
copies. Correcting `CLAUDE.md` alone leaves its own declared sources able to undo
the correction.

Purpose: make the provenance the markers assert actually true for the
fork-backend claims, so the every-session document stays corrected.
Output: three corrected source documents, each carrying a dated note saying what
was corrected and against what.
</objective>
