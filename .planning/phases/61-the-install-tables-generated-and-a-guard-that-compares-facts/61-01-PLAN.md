<objective>
Generate README.md's install tables from the frozen prerequisite declaration, and
stand up the record-comparison guard that keeps them honest.

This plan leads with a tracer: one thin path wired all the way through — read
`src/mcp/vice/prerequisites.json`, derive the VICE ecosystem rows, render them,
splice them into a marker-delimited region of `README.md`, and have a colocated
`node --test` guard parse that committed region back into records and compare it
against the same derivation. The second task expands the proven slice outward to
the second region (the eight-record overview) without changing the architecture.

Every commit in this plan that moves a `README.md` line also re-anchors the three
citation-ledger entries that point into it (D-08), and the tracer also retires the
line-pinned `prerequisites.test.ts` case the generated table supersedes — so the
suite is green after each commit rather than after the plan.

Purpose: `GEN-01` (the tables come from the declaration) and the first half of
`GEN-02` (the guard exists and compares parsed records). It closes the milestone's
last two-places-that-can-disagree.

Output: `src/mcp/vice/prereq-readme-gen.ts`, `src/mcp/vice/prereq-readme-gen.test.ts`,
two generated regions in `README.md`, a `generate:readme` npm script, and a
re-anchored citation ledger.
</objective>
