<objective>
Give the seam one exported reader for the declaration's remedy prose, so that every refusal
site plans 60-03 and 60-04 rewire quotes the declaration instead of re-authoring a sentence.

Purpose: `DECL-03` says a live refusal and the doctor cannot name different remedies for the
same tool. Today none of the eight records' `remedies` blocks is read by any shipped code
path at all — they exist only as data. This plan adds the FIRST runtime reader, in the one
module that already owns declaration lookup, so a second reader never gets written.

Output: `remedyTextsFor()` exported from `src/mcp/vice/tool-location.mts`, its compiled
artifact regenerated and committed, and the declaration's structural gate extended to police
the `remedies` shape this reader depends on.
</objective>

## Planner decisions recorded for this phase

There is no Phase 60 CONTEXT.md. The decisions below are the planner's, recorded visibly
rather than left implicit. Phase 58's `D-06` (OS-level platform keys with ecosystems nested
beneath), `D-09` (remedy strings are human prose containing a command, never a structured
argv) and Phase 59's `D-03` (the seam caches nothing) are binding and are not reopened.

- **PD-04: the declaration's remedy reader is a fifth export on `tool-location.mts`, not a
  new module.** Phase 59's `D-10` framed the seam as "two exports, and only two"; it shipped
  with four (`resolveTool`, `resolveOnPath`, `validateToolsFile`, `toolsFileTemplate`), and
  `toolsFileTemplate()` already reuses the module's private `readDeclaration()` reader for
  exactly this kind of prose. A separate module would need its own declaration lookup — a
  second reader of the same file, which is the disagreement `DECL-03` exists to remove.
- **PD-05: the reader returns an ordered list of plain strings, never a formatted sentence.**
  Each caller composes its own refusal sentence around them, because the surrounding prose
  differs per tool and per failure mode (unset variable, absent path, wrong kind). A
  formatter here would be the "remedy-text formatter" the research's `Don't Hand-Roll` table
  names as the thing not to build.
