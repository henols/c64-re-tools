<objective>
Ship the two service definitions a user can install by hand, and make "never
auto-applied" structural rather than aspirational.

Purpose: BROKER-05 asks for definitions that are committed and never applied, and
BROKER-02 asks that no client ever starts the broker. Both are promises that decay
silently unless something asserts them, and this project already has the shape for
that assertion — a tree scan with a planted-violation proof, which has been observed
biting.

Output: a systemd user unit, a launchd agent definition, a structural gate covering
both never-invoke promises, and the README section that tells a user which to copy
and what the universal fallback is.
</objective>
