<objective>
Measure the two experiments about **simultaneity**: whether two commands in flight
at once across the two channels interfere, and whether the binary side's existing
one-resume-per-wait / poll-on-hit-count discipline already tolerates a halt it did
not cause.

Purpose: the second of these is one of the milestone's two blocking UNVERIFIED
items, and `D-11` pre-mapped its `degrade` narrowing precisely because it is where
an after-the-fact author would be most tempted to declare the existing invariant
already sufficient. The narrowing is already committed: every stock module that
upholds the invariant natively must gain foreign-halt discrimination, and the shape
the verdict selects must supply it. This plan's job is to find out whether that
narrowing fires, not to argue about it.

Output: two probe scripts and two evidence files, each carrying one gate input at
column 0, plus the recorded overlap caveat.

**Serialization note:** this plan runs in its own wave because every probe refuses
to start when any other emulator process is alive — a real constraint from `D-16`
and Phase 33's recorded five-orphan incident, not a file conflict.

**Reversibility note:** the `one-way` ratings on this plan's tasks carry
`39-CONTEXT.md`'s own ratings forward rather than re-deriving them. No
`checkpoint:decision` precedes them because the owner already chose each of those
doors at `/gsd-discuss-phase` — re-asking a decision already recorded produces
checkpoint fatigue, not a gate. The phase's one genuinely unasked door, the rule
text and its ordering, is gated at `39-01` Task 1.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| the probe process → a directly spawned emulator (D-12) | The probe reaches the emulator by `execve` rather than through the broker, so none of the broker's guards apply: no single-client enforcement, no port allocation, no crash supervision, no pre-kill incident capture |
| an unsolicited broadcast-id frame → an outstanding wait | The collision under test: two of the five unsolicited types share a response type with a legitimate reply, so a wait keyed on the wrong signal could be satisfied by a stop it did not cause |
| a recorded overlap figure → a reader's belief about concurrency | A millisecond gap recorded without stating what kind of overlap it represents invites a stronger claim than the measurement supports |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
