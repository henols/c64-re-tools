<objective>
Promote the CLI's output shape to match the phase's: `anno export-asm --out` names a directory
and the verb writes a tree.

Purpose: this is the second half of the assumption-delta decision recorded in `47-01-PLAN.md`.
The exporter's primary output noun moved from one file to a tree of files, and a CLI still
handing back a single `.a` would leave two export shapes to keep in sync forever — shapes that
diverge the moment `external_file` lands, because a lone file cannot carry a `!binary` sibling.
Research left this explicitly open (Open Question 2) and asked that a plan decide it rather
than let it fall out of implementation.
Output: a directory-shaped `--out` with every existing confinement and input-collision safety
carried over intact, the invocation gate taught what the flag now means, and the shipped
skill's documented command made true again.
</objective>
