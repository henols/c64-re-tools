<objective>
Complete BUILD-01: make the partition real across many scopes, make the ambiguous case a
named refusal instead of a guess, make the output directory safe to write into, and make a
re-export a reviewable diff rather than unreviewable churn.

Purpose: plan 47-01 proved the path end to end on one scope. That is deliberately the
thinnest slice, and three things it left out are where this phase's real failure modes live:
a block belonging to no scope (every store in existence today, since `listScopes()` is read
by nothing), a range straddling a scope boundary (nothing in the schema prevents it — there
is no foreign key between `anno_range` and `anno_scope`), and a second export scribbling
over the first. Criterion 4's own words are that a re-export must be "a reviewable diff
rather than an unreviewable full-tree churn", which is a property that has to be asserted,
not hoped for.
Output: multi-scope partitioning with the unscoped group, the boundary-crossing refusal, the
output-directory contract, and the determinism drift guard plus every adjacency, empty and
ordering edge this phase owes.
</objective>
