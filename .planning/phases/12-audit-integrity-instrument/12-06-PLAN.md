carrying both a write indicator near a `*MILESTONE-AUDIT*.md` token and a gated
status token anywhere is in scope for the live hook. It refuses only when a docs

`audit-integrity.test.ts` and hand it to the child through `spawnSync`'s `input`
option; edit files with the Write and Edit tools, never `sed -i` and never a
heredoc; if you need a one-off CLI reproduction, write the payload to a scratch
file (whose name does not contain `MILESTONE-AUDIT`) with the Write tool and
redirect it in with `<`.

**Do not spawn a nested headless `claude -p` / `claude --print` session.** It
stalls the executor in this project and nothing here needs one.

**The deep-payload test builds its own JSON as a raw string.** `runHook()` passes
a string payload straight through without re-encoding — that is deliberate, and it
is the only way to build a 5,000-deep payload, because `JSON.stringify` blows its
own stack on that structure at around 20,000 levels and is needlessly slow well
before that. Build the string with `"[".repeat(5000)`, not with a nested array
literal.
</hazards>
