<objective>
Make the exported source structurally honest: every block asserts its own origin and its own
exclusive end so a length change cannot shift the code after it unnoticed; every typed data
range emits its exact bytes; and the one comment-text control this project does **not** have —
a refusal of embedded newlines — is built and proved.

Purpose: criterion 4 names the `*` assertion as the instrument that catches a zero-page-literal
substitution changing an instruction's length. RESEARCH.md measured that ACME exits 0 on exactly
that mistake, so the assertion is not decoration. And the pattern mapper found that
`assertCommentText()` performs three checks and none of them is a newline check — a stored `\n`
would emit arbitrary ACME source.

Output: an exporter that brackets every block, emits every data type, and refuses what it
cannot express; a store vocabulary that refuses a newline; and a test file carrying the
never-skipped ACME gate.
</objective>
