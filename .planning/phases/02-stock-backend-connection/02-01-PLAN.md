<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| committed fixture file → protocol parser | Bytes read off disk are fed straight into the frame parser; a corrupted or hand-edited fixture is indistinguishable from a hostile stream |
| emulator binmon socket → capture writer | The capture mode reads attacker-shaped-in-principle length fields off the socket and allocates against them |
| capture writer → repository | The capture mode writes files into the working tree at a path derived from a CLI flag |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Denial of Service | `probe-binmon.mjs` capture path | mitigate | Dump downstream of the existing `_onData()` loop so `MAX_BODY_LEN` (4 MiB) still gates every allocation; never re-parse the wire independently |
| T-02-06 | Tampering | `binmon-fixtures.ts` `loadCapturedFixture()` | mitigate | Sidecar must carry all four provenance keys or the load throws `MissingFixtureError`; `fixtures/binmon/README.md` records which fixtures are frozen evidence and must never be regenerated or hand-edited |
| T-02-08 | Denial of Service | `probe-binmon.mjs` `checkpoint-list` case | mitigate | `MAX_CAPTURE_FRAMES = 32` hard cap per case; single-address `stop=1` checkpoints only; deletion in a `finally` block so no armed checkpoint survives a crashed capture (the Phase 1 incident) |
| T-02-09 | Tampering | `--capture-out` path handling | mitigate | Resolve the output directory relative to the script's own directory, write via tmp-sibling → rename; do not interpolate the flag value into a shell command (`spawnSync` argv arrays only, no shell) |
| T-02-SC | Tampering | npm/pip/cargo installs | accept | This plan installs no packages. `zod` is deliberately NOT added (D-16) — `binmon-fixtures.ts` hand-copies the three pure constants instead. `package.json`'s `dependencies` block must be byte-identical after this plan |
</threat_model>
