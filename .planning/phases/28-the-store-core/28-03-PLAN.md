<objective>
Close the boundary Phase 27 left half-open, in both its halves, without moving a
single measured census number: teach `block-class.ts` the store's real lowercase
block vocabulary while keeping the external analyser's capitalised one working,
replace the header rationale that just became false, and pin both vocabularies
with derived total cross-checks so the failure mode — a measured coverage number
silently going to zero over a green suite — cannot recur.

Purpose: `blockClassAt` compares `block.type === "Code"` and
`block.type === "Undefined"` at `block-class.ts:131-132`, on a header rationale
at `:32-35` that explicitly rests on the store's vocabulary being capitalised.
The store's real vocabulary, read off `anno_set_data_type`'s own schema, is
lowercase. A correct new store therefore silently reclassifies every block as
`data`, with every existing test still green. The sibling label-kind vocabulary
(`"User"`/`"Auto"`/`"System"`/`"Platform"`) was never extracted at all and is
still compared inline at four sites, two of which empty the census's name map and
seed set.

Output: a boundary that accepts both vocabularies during the transition, a
replaced header rationale, a derived total cross-check over all twelve members, a
derived label-kind cross-check, and a test that makes the silent-zero loud.
</objective>
