<objective>
Close verification gap 1 (CR-01 + WR-02) and gap 2 (WR-01) by naming the one
invariant they are both routes into, instead of patching two symptoms.

The verifier's finding, in its own words: *"the snapshot ring has no ownership or
reconciliation discipline between its files and its pointer rows."* Today three
functions each decide independently what "retained" means —
`oldestRetainedRevision()` reads the rows, `revertTo()` reads a row, and
`pruneSnapshots()` iterates rows — and none of them consults the directory. The
first `revertTo` restores a pointer table whose files the prune already deleted,
and every one of the three then answers wrongly: the floor lies, the revert
crashes out of the `ViceError` family with the caller's handle already closed,
and 32 files are orphaned where the bound can no longer see them.

Purpose: after this plan there is exactly ONE definition of "revision `r` is
retained" — `retainedRevisions()` — and exactly ONE resolver for a half-state —
`reconcileSnapshotRing()`. Every consumer routes through them. A future reader
cannot reintroduce the disagreement by editing one of three places.

Output: the predicate, the resolver, a revert that refuses by name and returns a
usable handle, a prune whose statement order matches its own argument, a trap-10
comment that matches the code, and the two absent test scenarios this phase's
suite has never performed — a second revert, and a mid-prune interruption — each
with a planting that is observed to go red.
</objective>

closure actually raises:

- **The noun that is now primary.** A **retained revision** is no longer "a row
  in `anno_snapshot`". A second source of truth for revertibility — the
  `snapshots/` directory — has always existed, and the whole gap set is what
  happens when the two disagree. The generalized identity is *the (pointer row,
  snapshot file) pair that agrees*.

  `retainedRevisions()` returns the reconciled set and becomes the single

  the three disagreeing answers arose.
- **Rationale.** With `promote`, a future edit that reintroduces the singular
  assumption has to delete the `existsSync` filter inside one named function —

  regression cannot land silently.
