<objective>
Close WR-12, the confinement regression 28-12 introduced, and then close out the
round with the gate that re-establishes the requirements round 3 reverted.

Purpose: 28-12 correctly replaced `existsSync` with `lstat` in the ancestor walk,
but `lstatSync(p, { throwIfNoEntry: false })` suppresses **ENOENT only**. So the
ordinary caller path `<ws>/notes.txt/p.annostore` — an ancestor that is a regular
file — escapes `openStore` as a bare `Error: ENOTDIR`, an unreadable ancestor
escapes as a bare `EACCES`, and an ANCESTOR symlink cycle escapes as a bare
`ELOOP`, while the LEAF cycle 28-12's own test plants correctly refuses with
`AnnoStorePathError` naming the 40-hop bound. Before 28-12 all three refused by
name. The confinement outcome is still right on those inputs, but it is right for
the wrong reason — an unhandled OS error rather than a decision — and the module's
own doc comment claims otherwise, which is a live 28-07 P3 violation.

Output: one wrapped predicate, three confinement cases that pin the three input
classes, and a closing regression gate.

re-implements them. All six STORE requirements were reverted OUT of Complete in

stay so. Task 3 is the gate that re-establishes them by regression and by
