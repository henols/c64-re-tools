The assumption-delta detector fired on this phase — `kind: pluralization` on
"second" and "another", `kind: chosen` on "chosen". It is advisory and never

**Noun 1 — "the annotation store". Decision: `promote`.**

Until this plan, "the annotation store" meant, implicitly and in every consumer,
*regenerator2000's* `.regen2000proj` store — a single source this project rented.
This plan makes this project the owner, and `REQUIREMENTS.md`'s owner decision 1
removes any parity obligation to the old one. So the generalized identity —
**the annotation store, whoever owns it** — becomes primary, and
regenerator2000's store is demoted to a historical detail of one variant that
`CUT-01` deletes. There is no plural to maintain and therefore no
add-alongside: after this milestone exactly one store exists.

What would force a re-examination: a shipped code path that reads
`.regen2000proj` as a store. None is built here, deliberately (see
`<research_corrections_applied>`), and its absence is what makes the promote
real rather than nominal.

**Noun 2 — "a second, independently written implementation" (criterion 2's
cross-validation oracle). Decision: `no-change`.**

This is a **test artifact, not a pluralization of the index abstraction.** There
is exactly one production narrowest-wins implementation — `buildPaintIndex` plus
`resolveAt` in `anno-index.ts`. The scan oracle exists only inside
`anno-index.test.ts`, is never exported, and never enters `package.json`'s
`files[]`. Saying so explicitly is the point of this block: a reader who takes
"two independent implementations" as a requirement on the *production*
abstraction would conclude the index needs a strategy seam or an injectable
comparator, and that is exactly wrong — it would give the store two answers to
"what type is this address" and destroy the very property the cross-validation
exists to prove.

**Optional, not required:** a contract test worth considering in a later plan —
assert that no shipped module names the `.regen2000proj` extension, pinning
"this project owns its store" as a structural fact rather than an intention.
Recorded as a suggestion only; nothing in this phase depends on it.
