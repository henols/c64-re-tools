| id | accepted keys | path-bearing keys | non-path remainder |
|---|---|---|---|
| `petcat.decode` | `image`, `outDir` | `image`, `outDir` | — |

`outDir` is optional and defaults to `dirname(imagePath)`.
argv: the fixed dialect flag first, then the resolved image path last.
`outputs[0]`: `<outDir>/<imageStem>.bas.txt`.
Member of `TOOLS_WHOSE_OUTPUT_IS_STDOUT`.

**Declared success shape:** the leading banner line the tool emits, of the form
`;<path> ==<hex>==`. Absence of it is the failure.

**Response, and ONLY for this id**, two extra fields alongside the five the
success envelope already carries:
`entrypoint: number | null` and `entrypointReason: string`.
- literal case → `entrypoint` is the decimal argument as a number,
  `entrypointReason` names the line it came from.
- computed case → `entrypoint` is `null`, `entrypointReason` quotes the
  expression verbatim.
- no `SYS` token found at all → `entrypoint` is `null`, `entrypointReason` says
  the listing contains no handover instruction.
All three are `ok: true`: the tool worked and reached a real answer. `ok: false`
is reserved for the shape oracle.

**Declared path-key census total after this plan: 29** (27 after 40-02, plus this
id's two). Recompute rather than trust the number; a mismatch means a key was
added or dropped.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| container-side skill script → `host_tool` seam | `image` and `outDir` are untrusted input. |
| host seam → host process execution | A second external binary is now driven by container-side input. |
| the detokenized listing → the handover verdict | Text produced by an external tool over attacker-influenceable bytes is parsed host-side. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-40-03-01 | Tampering / Information Disclosure | `image` and `outDir` on the decode id | high | mitigate | Both keys are declared path-bearing and resolved through the existing symlink-safe workspace confinement; the both-directions census fails if either is omitted from the table. |
| T-40-03-02 | Elevation of Privilege | the fixed dialect flag | high | mitigate | The dialect is a server-side constant in the one argv-construction site; no wire key selects it, so no caller can inject an extra flag through it. |
| T-40-03-03 | Tampering | the handover verdict parsed from tool-produced text | medium | mitigate | The literal branch accepts only an all-decimal-digit argument and converts it as a number; anything else takes the decline branch with the expression quoted verbatim. There is no path that turns an unparsed expression into an address. |
| T-40-03-04 | Denial of Service | a hung converter process | medium | mitigate | A `HOST_TOOL_TIMEOUT_MS` entry justified from a measurement, with the existing kill-on-expiry timer; the completeness assertion fails CI if the id ships without one. |
