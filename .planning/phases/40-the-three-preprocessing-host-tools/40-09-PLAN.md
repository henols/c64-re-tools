<objective>
Close gap G-40-1's second binding requirement (R2) and land the two guards the
diagnosis says this design must ship with.

Purpose: plan 40-08 made the handle exist and made it verified. This plan makes THE
BROKER the thing that creates it -- the owner's literal requirement, and the only
arrangement under which a container-side MCP server with no host tooling inside it
keeps working. It also closes the two ways this design can rot silently: a
caller-supplied path routed through the handle (which `resolveWorkspacePath()` would
realpath straight back to the dotted path), and an upstream Ghidra change from
`getAbsolutePath()` to `getCanonicalPath()` (which would break every run at once, 12-16
seconds late, with an error naming a path the user never typed).

Output: the broker startup call site with its committed artifact, the remaining
consumer migration, and two non-vacuous guards -- one structural in the automated
suite, one live and opt-in.
</objective>
