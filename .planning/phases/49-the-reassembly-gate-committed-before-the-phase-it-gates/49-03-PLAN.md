<objective>
Plant the three controls the phase criteria name and watch the gate go red on each of them,
before any green result from it is trusted.

Purpose: a gate that has only ever been seen passing is indistinguishable from a gate that
always passes. The three failure shapes chosen here are not hypothetical — a wrong byte under
an exit-zero assembler is this project's own recorded false pass, a stale output path is the
documented reason the oracle assembles into a fresh directory every time, and a clean byte-diff
over a scope that quietly stopped covering the interesting range is the failure mode a
byte-diff cannot see on its own.
Output: three paired honest-then-red controls, the test-only seam that makes the stale-artifact
one plantable at all, and the adjacency cases that pin the scope check's boundary behaviour.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a planted output directory → the verdict body's absent-before-spawn check | The one boundary this plan deliberately opens, so the check can be observed rather than assumed. |
| a narrowed store → the export's reported extent → the scope check | A change upstream of the byte-diff that the byte-diff itself cannot see. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-49-08 | Repudiation (false assurance) | the planted controls themselves | high | mitigate | A control that would fail for any reason proves nothing, and a control that silently stops firing removes trust nobody notices. Mitigated by pairing every red with an honest control in the same case against the same tree, by asserting the assembler really spoke in the honest direction, and by counting the named cases in a verify command so a deleted control fails the task. |
| T-49-09 | Tampering | the new test-only output-directory seam | high | mitigate | A seam that lets a caller point the output somewhere could be mistaken for a way to reach a pass from a pre-existing artifact. Mitigated by the absent-before-spawn conjunct running unchanged against anything passed through it — which is exactly what the planted control demonstrates — by documenting the bound on the seam itself, and by the seam being optional with a fresh directory as its default. |
| T-49-10 | Information Disclosure | caller-supplied output directory | low | accept | The directory is supplied only by in-repository test code and points at a temporary directory that test created. No external caller reaches this option and nothing outside the supplied directory is written. Accepted at the configured assurance level for a development-time gate. |
| T-49-SC | Tampering | npm / pip / cargo installs | high | accept | No package-manager install task exists in this plan; the only external tool is the assembler, detected and never installed, reached through the existing availability gate. |
</threat_model>
