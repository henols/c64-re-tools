<objective>
Make movement a thing the gate does on every run rather than a thing it could do: relocate a
symbol, rebuild at the new layout, and let the byte-diff at that new layout be the answer.

Purpose: a rebuild that only ever reassembles at the addresses it was decompiled from proves
the bytes round-trip, not that the source is movable — and movability is the entire point of
symbolising every reference. Nothing in this codebase relocates a symbol in place today; every
existing test builds a fresh subject at a fresh address instead. This plan builds that missing
operation at the store-and-image layer, so the check exercises the real export path rather than
a hand-edited artifact.
Output: a relocation transform with its refusals, a movement result the gate consumes, and the
half-moved split-table control observed catching the half that was left behind.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| the declared reference-site list → the bytes the transform writes into the rebuilt image | Fixture data decides which image bytes are addresses; a wrong declaration writes an address over something that is not one. |
| the transformed store document → the exporter → the assembler | A relocation that shifts rows inconsistently produces a tree that assembles to bytes nobody intended. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-49-11 | Tampering | the declared reference sites | high | mitigate | A stale or wrong site declaration silently patches bytes that are not an address, and the resulting byte-diff blames the exporter for the fixture's mistake. Mitigated by refusing, by name, any site whose current bytes do not already hold the moved symbol's original address under its declared encoding, and by refusing any site naming a symbol other than the one being moved. |
| T-49-12 | Repudiation (false assurance) | a movement that did not move | high | mitigate | A same-address round trip scored as a movement pass would make the whole criterion cosmetic. Mitigated three ways: a zero delta is refused inside the transform; the result builder returns the refused token whenever the two addresses are equal whatever the assembler said; and the gate's rule table maps the refused token to red. |
| T-49-13 | Tampering | the rebuilt image buffer | medium | mitigate | Relocating by patching the image in place would leave the moved bytes at both addresses and could overwrite a neighbour. Mitigated by rebuilding the buffer from scratch and copying each range to its new address, and by refusing a relocation whose new extent intersects another range's, with the abutting case explicitly allowed and the shared-address case explicitly refused. |
| T-49-14 | Denial of Service | the rebuilt image's size | low | accept | The buffer spans the transformed document's own lowest-to-highest range extent; a caller could in principle supply a delta that makes that span very large. Accepted: every caller is in-repository test code supplying its own fixture, the transform performs no allocation loop and no recursion, and no external input reaches it. |
| T-49-SC | Tampering | npm / pip / cargo installs | high | accept | No package-manager install task exists in this plan; the only external tool is the assembler, detected and never installed, reached through the existing availability gate. |
