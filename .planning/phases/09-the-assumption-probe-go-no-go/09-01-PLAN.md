<objective>
Stand up everything this phase needs that does not exist yet, and answer the first half
of criterion 1: **a real regenerator2000 build is present and identified in this
environment, with its version recorded** (`R2000-16`(5)).

Purpose: every other criterion's evidence is qualified by the version that actually
installed. `cargo install regenerator2000` may not fetch code byte-identical to the
`df4bc94` clone `09-RESEARCH.md` read, so the installed `--version` and the resolved
crate version are themselves findings, not bookkeeping (Evidence Integrity Rule 3).

This plan also builds the one fixture the phase cannot proceed without. **No `.prg`
fixture exists in this repo**, and `.claude/skills/acme-build/template.a` uses **no
illegal opcodes**, so it is a weak fixture for the `!cpu 6510` question criterion 3(2)
actually needs answered.

Output: `evidence/criterion0-prerequisites.txt`, `evidence/criterion1-install-and-version.txt`,
`evidence/fixture/probe-illegal.a`, `evidence/fixture/probe-illegal.prg`, plus a
worktree-independent copy of the fixture under `$HOME/.cache/c64-re-tools/phase9/`.

**This plan builds no product code.** It must not touch `.claude/mcp/vice/`. If it finds
itself editing the MCP server, scope has drifted — stop.
