**Research correction:** 09-RESEARCH.md's data-flow diagram (Architecture
Patterns) shows step ⑤ `auto_analyze()` running unattended straight into step ⑥
(MCP server start). In fact an "Import Context Setup" confirmation dialog is
presented and holds focus before analysis proceeds -- this is an additional modal
the bootstrap sequence must dismiss (via Escape or Enter-on-Confirm) before Alt+S
can reach the Save-As dialog. Not fatal to 2a (the MCP server started regardless,
per the status bar), but it changes the exact keystroke sequence 2b needs.
