**Real finding, source-confirmed and now independently reproduced against the
actual file bytes (not inferred): the VSF's own `machine_name` field is
literally `"C64SC"` -- x64sc's own model designation -- not the bare `"C64"`
string `file_io.rs:102-109`'s match arm compares against
(`"C64" => Some(System::C64), "C128" => ..., _ => None`). `"C64SC" != "C64"`
under Rust's `==`, so this match falls through to `_ => None`.** This is a
real, concrete, source-grounded prediction (not yet confirmed against the live
TUI pane -- that is Task 2's job) that regenerator2000's `suggested_system`
inference will NOT recognise a genuine x64sc-produced snapshot's machine type
string, even though the snapshot format itself does carry a real machine
identifier. Recorded now, checked against the live pane in Task 2, and folded
into the R2000_DERIVED comparison in Task 3.
