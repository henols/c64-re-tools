Capture a depacked flat-64K image of the running release, then run PROOF-02's
independent site search over the real game code for the first time — and record
the roll-up verdict whichever way it comes out.

honestly scoped answer if this capture proves infeasible.

roll-up record `evidence/proof02-computed-dispatch.md`.
