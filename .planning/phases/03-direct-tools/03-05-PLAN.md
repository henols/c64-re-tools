    wrong, `stepOver: true` silently behaves like a plain single-instruction step

    direction or fire never registers. Note that `joyportSetBody()` deliberately
    takes an already-composed raw `value`, so the assumed mapping lives in exactly
    one function to correct.

    differently when `runAfter` is 0, the approximation could attempt to locate
    and partially load a specific program even with run suppressed.

    `stock-checkpoints.ts`'s D-11 rate limiter defers its auto-disable
    `CHECKPOINT_TOGGLE` out of the `'event'` callback stack. Whether the chosen
    deferral is race-free under a real synchronous `CHECKPOINT_INFO` flood is only
    observable against a real emulator.
