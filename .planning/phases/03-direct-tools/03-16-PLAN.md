<objective>
Turn the UAT's ad-hoc live probe into a committed, repeatable gate, and use it to
re-verify the blocker that plan 03-14 fixes.

03-UAT.md test 5 established two things that only a live run can settle:
`vice_registers_set` refused every real register, and the flag-bit refusal path
downstream of that check was therefore **never reached** and remains unverified.
Plan 03-14 fixes the width check and proves it with a wire-shaped fixture; this
plan proves it against the emulator.

Two environment facts, already established and not to be re-discovered:
- `/usr/local/bin/x64sc` (VICE 3.10, the fork build, has `-mcpserver`) shadows
  `/usr/bin/x64sc` (VICE 3.9, genuinely unpatched) on PATH. The stock binary must
  be named by absolute path or every "stock" check silently exercises the fork.
- Both builds share `$HOME/.config/vice/vicerc`, and the 3.10 build has written
  it, so spawning 3.9 raises a modal "Configuration file version mismatch"
  dialog. Pointing `XDG_CONFIG_HOME` at a scratch dir silences it.

Purpose: DIRECT-02's "writes a register and echoes back the value the emulator
confirmed" has no live evidence today, and the phase cannot honestly be verified
without it.
Output: `stock-live.test.ts`, opt-in and skipped by default, plus the recorded
live evidence.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test process -> spawned emulator | a child process with full machine control is created and must be reaped |
| binary monitor socket -> network | the monitor is unauthenticated: whoever reaches the port owns the emulated machine and can read/write host-reachable files through it |
| host config dir -> spawned binary | two VICE versions share `$HOME/.config/vice/vicerc` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-16-01 | Information Disclosure | `-binarymonitoraddress` bind address | mitigate | Bind `ip4://127.0.0.1` on an ephemeral port only; never `0.0.0.0` and never a fixed well-known port (this is the standing QUAL-03 control-plane-exposure concern, honoured rather than deferred) |
| T-03-16-02 | Denial of Service | orphaned `x64sc` child / leaked socket | mitigate | Teardown SIGKILLs the child and awaits exit, `client.disconnect()` closes the socket, everything is acquired inside the guarded region, and the live verify runs under `timeout 180` |
| T-03-16-03 | Tampering | spawning the wrong binary | mitigate | Absolute path from `VICE_LIVE_STOCK_BIN` defaulting to `/usr/bin/x64sc`; a bare PATH lookup is explicitly forbidden and the skip reason says why |
| T-03-16-04 | Tampering | polluting the developer's VICE config | mitigate | `XDG_CONFIG_HOME` points at a per-run `mkdtempSync()` dir, removed in teardown; the shared `vicerc` is never written |
| T-03-16-05 | Repudiation | a live gate that silently skips in CI and is mistaken for evidence | mitigate | Default-skip prints an explicit reason; task 2's verify demands `skipped 0`, so "it skipped" can never be recorded as "it passed" |
| T-03-16-SC | Tampering | package installs | accept | No npm/pip/cargo install in this plan; slopcheck N/A |
</threat_model>
