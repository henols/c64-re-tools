Classify them mechanically rather than by judgement. A member is `re-pointed` when Phase 29's work

`hop-chain-comments.test.ts`, `hostpath-consumers.test.ts`, `skill-acme-build-cli.test.ts`,
`stock-dispatch.test.ts`, `tool-support-table.test.mjs`, `vice-proxy.test.ts`.

The 3 `kept-unchanged`: `scripts/lib/skill-descriptions.mjs`,
`src/mcp/vice/skill-attribution.test.ts`, `src/mcp/vice/stock-connect.test.ts`. Note that research

divergence with the command rather than overriding the rule.

**The landmine this plan owns.** `src/mcp/vice/vice-proxy.test.ts` is one of the nine
`MANUAL_ONLY_TESTS` and it HANGS locally. The harness's fail-closed error mapping reports an
ETIMEDOUT as status 1, which is exit-status-indistinguishable from a genuine failing assertion. A
timeout accepted as an observed red would be a false red — precisely the vacuity `CUT-04` exists to
catch. The green false-positive control is what makes this safe: the unplanted guard must exit 0
first. Debugging the hang is explicitly out of scope; RECORDING it is not.

Wave ordering: every audited guard was modified in waves 2-3; this plan only measures.
