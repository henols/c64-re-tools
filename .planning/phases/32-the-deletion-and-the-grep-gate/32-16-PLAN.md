scripts that still hand-roll `--root`.**

**What the verifier measured.** `audit-gate.mjs`'s `parseArgs()` at `:1118-1131` carries the
original round-1 defect intact and then some: it takes `argv[i + 1]` with no missing-value
check, and it SILENTLY DROPS any token it does not recognise. So `--root=/tmp`, a bare
`--root` and the typo `--rooot /tmp` all fall through and produce the full real-tree gate
report. Three invocations, three identical real-tree runs, none of them mentioning `--root`.

**The decision this plan takes, and why it is not the obvious one.** `gaps[0].missing[1]`
names exactly one remedy: wire the script to `parseRootArg()`, preserving its existing flags
through `booleanFlags`. It does NOT ask for `resolveContainedRoot()`, and this plan does not
add it. That is deliberate and measured, not a shortcut:

- **This script never writes.** Measured over comment-stripped source across the whole
  filesystem-write API set — not `writeFileSync` alone — the count is 0, and the fs import
  surface is exactly `{ readdirSync, readFileSync }`. Round 2's own review records this as an
  explicit correction to round 1, whose `WR-13` had asserted that it writes. Containment exists in `scripts/lib/audit-root.mjs` for a flag that
  decides which tree a script reads AND WRITES; the trust boundary it guards is the write.
- **Its own test suite deliberately points it at out-of-repository trees**, with a recorded
  design argument at `src/mcp/vice/audit-integrity.test.ts:162-171`: a committed fixture
  literally named `docs-*.test.ts` would join the real guard glob and red CI permanently, so
  the synthetic tree lives outside the repository where it is structurally incapable of doing
  that. Adding containment would force either the relocation of that idiom — overriding a
  recorded decision this round was not asked to re-take — or an `allowExtra` escape wide
  enough to cover any temp directory, which is the relaxation hatch the seam's own header
  forbids.
- **The asymmetry becomes a guarded invariant rather than a silent one.** Plan 32-18 pins it:
  the completeness matrix carries `audit-gate` with a typed expectation that says
  uncontained-by-design, and an assertion that the file contains zero write calls. The moment
  `audit-gate.mjs` gains a write, that assertion reds and forces containment. That is
  strictly stronger than containment-by-default, which would have left the reason unstated.
