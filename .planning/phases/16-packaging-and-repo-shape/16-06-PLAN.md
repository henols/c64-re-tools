<objective>
Give the three skill CLI scripts the tests they have been owed since the v0.2.0 scoping
deferral — as three committed files inside the module package, each discovered by the ordinary
test glob, each driving its subject the way that subject's real surface allows.

Purpose: PKG-02 inherits QUAL-01, deferred at v0.2.0 scoping and carried through two
milestones. These three scripts are the executable half of three skills: one assembles C64
sources, one resolves addresses and annotates listings, one derives VIC and sprite layout and
reads reset vectors out of a memory image. All three are shipped to consumers, all three are
invoked by hand or by a playbook, and none has ever had a test.

One mechanical constraint shapes the whole plan and is worth stating before any task: test
discovery in this package is a non-recursive listing of a single directory. A test file placed
next to the script it exercises is never executed — by the plain glob or by the automated
gate. So these three files live in the module package and reach across into the sibling skills
tree by relative path. This is not a preference; a file in the "natural" place would be dead.

The three subjects differ in how they can be driven, and the plan follows the difference
rather than forcing uniformity: the memory-map driver guards its dispatch and exports its
lookup function, so pure lookups are asserted in-process; the other two dispatch at module
scope, so every case is a subprocess. Where a subprocess is used it is an argument vector,
never a shell string.

**Reversibility:** `reversible`. Three new test files and no production change; deleting them
restores the prior state exactly. A plan prohibition forbids editing the scripts themselves,
so there is no production surface to unwind.

Output: three test files, a suite total above the 2292-test pre-phase baseline, and no new
entry in the manual-only exclusion list.
</objective>
