<objective>
Close audit item **I-2** (CRITICAL) at its single root cause, and close the **I-1**
rider in the same pass because it shares the fix site.

**I-2:** `buildViceArgs()`'s stock branch (`broker-launch.mts`, the
`if (backend === "stock")` block) emits `-binarymonitor`, `-binarymonitoraddress`
and optionally the `-remotemonitor` pair — and **no drive configuration of any
kind**. A broker-launched stock `x64sc` therefore boots with `Drive8Type=0` (NONE),
nothing answers unit 8, `LOAD"*",8,1` returns `?DEVICE NOT PRESENT ERROR`, the
entry-point checkpoint never hits, and DIST-03's verified 64K capture is
unreachable. No stock MCP tool can correct it: the 38-tool stock manifest has zero
resource-set names by design (Phase 6 cut GAIN-08/09). The confirmed sufficient fix,
proven live in Phase 8.1's own standalone probe, is `-drive8type 1541` at launch.

**I-1 (rider):** `spawnFn` is still `(command, args) => ChildProcess`, so production
stock launches set no scratch `XDG_CONFIG_HOME` and read whatever `vicerc` the
operator's `$HOME` already carries — while every live test in the tree sets one.
Give `spawnFn` an options parameter and thread a fresh scratch `XDG_CONFIG_HOME`
for stock launches. The audit is explicit that I-1 and I-2 are the same *shape* and
different root causes: `-default`/`XDG_CONFIG_HOME` would not configure
`Drive8Type`, and `-drive8type` would not add config isolation. Both land here;
neither task's acceptance criteria may absorb the other's.

Purpose: item 1 of the ROADMAP's four ordered items. It must land **before** item 3
(plan 04) — the walkthrough re-run has nothing new to prove until this exists.
Output: a fixed `buildViceArgs()`, a widened `spawnFn`, unit proof of both, and a
regenerated, committed `resources/broker-launch.mjs`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| broker daemon → emulator process | The broker composes argv and env for a child process running on the bare host; everything it puts there is executed with the operator's privileges |
| broker daemon → operator's `$HOME` | Without isolation, a launched emulator reads and can rewrite `$HOME/.config/vice/vicerc`, which is shared with the operator's own VICE usage and with the fork build |
| emulator → localhost TCP | `-binarymonitor` binds an unauthenticated full-memory-read/write control socket; the loopback default is the safe posture |
