# Phase 08.2 Plan 02: Fix stock Drive8Type=0 defect and widen spawnFn for config isolation Summary

**Stock `buildViceArgs()` now emits `-default -drive8type 1541` ahead of `-binarymonitor` from one fix site (closes I-2/FINDING-C1), and `spawnFn` gained an optional options argument so `spawnAndRecordInstance()` can thread a fresh `mkdtempSync` `XDG_CONFIG_HOME` through for stock launches only (I-1 rider, seam half).**

## Accomplishments

- Closed audit item I-2 (CRITICAL, §4.2, FINDING-C1): a broker-launched stock `x64sc` used to boot with `Drive8Type=0` (NONE), so `LOAD"*",8,1` failed `?DEVICE NOT PRESENT ERROR` and DIST-03's verified 64K capture was unreachable through the broker. The stock branch of `buildViceArgs()` now returns `["-default", "-drive8type", "1541", "-binarymonitor", "-binarymonitoraddress", "ip4://<host>:<port>"]` (plus the existing `-remotemonitor` append when `remoteMonitorPort` is supplied) from a single fix site.
- Proved, with a unit assertion that survives future flag additions rather than a brittle exact-array check alone, that `-default` sits at index 0 and `-drive8type` precedes `-binarymonitor` in both the plain and `remoteMonitorPort` variants.
- Kept the fork backend's argv byte-identical (BACK-02 standing regression gate, unmodified test still green) and left `stock-machine.ts` untouched — the defect was entirely a launch-time argv omission, not a wire-encoding bug.
- Widened `TryLaunchDeps.spawn`, `AcquirePortAndLaunchDeps.spawn`, and `AcquirePortAndLaunchDeps.spawnFactory`'s return type to an optional third `SpawnOptionsWithoutStdio` argument, with every pre-existing 2-arg caller and test stub continuing to compile and behave identically.
- `spawnAndRecordInstance()` now computes a fresh `mkdtempSync(join(tmpdir(), "vice-broker-vicerc-"))` scratch directory and passes `{ env: { ...process.env, XDG_CONFIG_HOME: scratchDir } }` as spawnFn's third argument, but only for `backend === "stock"`; fork launches call `spawnFn(viceBin, viceArgs)` with no third argument at all, matching the pre-plan call shape exactly.
- Regenerated and committed `resources/broker-launch.mjs`; `resources-sync.test.ts` confirms it is byte-identical to a fresh `node build.ts` compile.
