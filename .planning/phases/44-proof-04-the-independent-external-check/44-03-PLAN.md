## WHAT THIS PHASE DOES NOT CLOSE

The record states each of these plainly, because a reader finding them absent
would otherwise read the absence as coverage:

- `PROOF-03` on real cracked code stays carried and unowned. It was proven in
  both directions on a synthetic two-caller fixture; the `danish.d64` question
  stays open and stays recorded as open. Nothing in this phase satisfies it,
  including as a side effect.
- `ANNO-13` / `ANNO-14` / `ANNO-15` are not restored. The 2026-08-26 "no parity
  is owed" decision stands.
- The carried v0.8.0 limits are unchanged and still bind: `S3` is frame-exact
  and byte-identical to anchor hit 50 and diverging from hit 75, because
  `AUTOSTART`'s power cycle does not reset the absolute emulated clock.
- The self-modification bound from plan 44-02: an observed execute proves the
  address held code at that moment, which is a genuine miss by the byte-derived
  tier either way, but does not by itself prove the original file byte at that
  address was code.
- The subject is dxa alone. Ghidra strengthening and a `chis` cross-check were
  both available and both declined (planner decision D-P6), because dxa alone
  is the classifier whose count `PROOF-01` left uncomputable.
- One release. `saeger.d64` was not taken (D-P3), so the count distinguishes
  nothing about dxa in general -- only about dxa on this binary.
