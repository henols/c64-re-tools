**Run A — stock VICE 3.9, port 6502.** Launch in the background with
`DISPLAY=:0 /usr/bin/x64sc -binarymonitor -binarymonitoraddress ip4://127.0.0.1:6502 -drive8truedrive -drive8type 1541`.

`RESOURCE_SET` opcode. Do not pass `-warp`; a warped boot changes the timing the raster-condition

a temporary file outside the repo, for example under `/tmp`. Then terminate that emulator process
before starting the next one — VICE's binary monitor services exactly one client per instance and
running one at a time removes any ambiguity about which port produced which output.

`DISPLAY=:0 /usr/local/bin/x64sc -binarymonitor -binarymonitoraddress ip4://127.0.0.1:6503 -drive8truedrive -drive8type 1541`
