<objective>
Produce the three remaining "observed red" controls the success criteria demand,
and re-check `probeReady`'s wall-clock budget under both new launch flags.

Purpose: each of these three criteria says the same thing in a different place —
the property must be **observed**, not argued. Launch nondeterminism is proven
pinned by *divergence* rather than by a flag's presence. The reset step is proven
load-bearing by removing it and watching the stops diverge. The frame term's
necessity is proven by a control in which `(LIN, CYC)` **alone passes** on two
stops one frame apart, so the anchor is shown to be doing work rather than
asserted to be.

A control whose entire purpose is to be red cannot live in a suite whose contract
is to be green, and the corpus-dependent ones cannot run on a machine without the
corpus at all — so each is a committed transcript produced by a named repeatable
script under the phase directory, not a test-suite assertion.

Output: three transcripts carrying three of `GATE-01`'s five inputs at column 0,
plus `D-18`'s re-check.

**This plan carries `D-18` on 33-06's behalf.** `D-18` asks for the re-check "in
the same plan that adds the profile"; it is a live, broker-stopped measurement, so
it sits here with every other live measurement in the phase, and it is widened
from `-warp` alone to cover `-console` as well (research observed one `-console`
launch not yet bound at 3000 ms and bound at 5000 ms). `33-06`'s objective records
the same placement.

This is a **live** plan and it is alone in its wave. Stock's binary monitor serves
exactly one client.
