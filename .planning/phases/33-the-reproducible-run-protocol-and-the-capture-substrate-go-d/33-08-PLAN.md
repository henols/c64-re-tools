<objective>
Give the transient allow-list a derivation method rather than an address set, and
give every capture record the three-field reproducibility key.

Purpose: `CAP-02` says the method is what carries forward, never any address set —
a real release's transients are its own frame counters, RNG, sprite positions and
music-player pointers, and an allow-list inherited from another release cannot be
distinguished afterwards from one honestly derived. And `REPRO-04` exists because
the seed alone is not the key: the **same seed with a reordered argv was measured
to yield a 76-byte-different image**. A record keyed on the seed alone claims
reproducibility it does not have.

The cap is a pre-commitment, and this plan builds it to **void** rather than warn.
The reasoning is worth stating plainly because the first real derivation may hit
it: measured, a frame-exact stop at the `READY` prompt gives 0 differing
addresses, a wall-clock stop with the determinism block gives 1242, and a
wall-clock autostarted stop on a real release gives 300. The cap does not
distinguish "a few transients" from "a lot of transients" — it distinguishes "the
stop is frame-exact" from "the stop is not", which is the fact `GATE-01` must
hear.

Output: a named repeatable derivation script with a colocated test, the capture
record's Identity table extended and its volatility note re-grounded, and a
per-release artifact directory that refuses image bytes before the first capture
exists.
</objective>

**Verb `derive`.** Signature:
`derive --release <id> --out <path> [--cap <n>] <image1> <image2> <image3> [...]`.

- Refuse fewer than three images, naming the count and the minimum. Three runs is
  already this project's documented minimum for a verified capture, and the method
  is `N >= 3`.
- Refuse an image of any length other than 65536, naming the path and the length —
  reuse `compare.mjs`'s exact-size load refusal in kind.
- Compute the union of addresses differing across **every pairwise comparison**,
  which for N images is N(N-1)/2 pairs. Structurally this is `cmdFloor()`'s
  existing derivation; copy its shape, not its classification.
- For each address in the union, record: the address, the run pairs it differed in
  (by the image basenames, so the record is readable), the distinct byte values
  seen, and an optional one-line attribution field left empty for a human to fill.
- `--cap` defaults to 64 and must match `TRANSIENT_ALLOW_LIST_CAP`. When the union
  size exceeds the cap: print a message stating that the derivation is **VOID**,
  naming the union size and the cap, and stating the reason in one line — the stop
  is not frame-exact, and that is a fact the gate must hear rather than a threshold
  to raise. Exit **non-zero** and write **no artifact**. Do not write a partial
  file, do not write a truncated list, and do not print the word "warning".
- On success write the artifact to `--out` as JSON: a `schema_version`, the
  `release` id, the ordered image basenames the derivation used, the pair count,
  and the `entries` array ascending by address. Print the union size and the cap.
- Emit one outcome line at column 0 on stdout, `TRANSIENT_COUNT: <n>`, so a
  measuring plan can transcribe it into an evidence file rather than paraphrase it.

**Verb `check`.** `check --allow-list <path> <imageA> <imageB>` — load a committed
artifact and two images, and print the equivalence verdict plus the differing and
allowed address lists. This is the verb an operator uses to re-check a pair
against an existing derivation without re-deriving it. It must produce the same
verdict the MCP-side predicate produces for the same inputs; the colocated test
asserts that agreement on a synthetic case rather than leaving it to trust.

**Never inherit an address set.** Reject a `--release` id whose artifact already
exists at `--out` unless an explicit `--force` is given, and state in the refusal
that the list is re-derived per release and never carried across. An allow-list
inherited between releases cannot be distinguished afterwards from an honestly
derived one, so a contaminated ledger has to be re-derived from fresh captures.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| captured `.bin` images → `derive-transients.mjs` | Untrusted binary input; the derivation it produces decides which future differences are excluded from a verdict |
| the derived allow-list artifact → `parseAllowList` on the MCP side | An artifact widened by hand would silently widen every later comparison |
| the per-release artifact directory → git | The directory sits beside capture output and will be written to by an operator mid-session |
