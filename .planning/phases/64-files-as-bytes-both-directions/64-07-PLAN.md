Prove the phase's own headline claim and record what the proof is worth.

Purpose: `XFER-08` and the ROADMAP's criterion 1 both say all four tools work with
no shared filesystem between client and broker. D-17 chose how that is proved —
disjoint roots plus observation — AGAINST the recommendation offered, and recorded
the weaker guarantee that choice buys. D-18 chose that the convergence metric is
measured and recorded rather than gated, because an importer count is a text question
and asserting on text is banned.

This plan does both, and writes down the limits of both so that nobody later
mistakes a green test for a stronger claim than it makes.

Output: one integration test driving all four handlers across two roots that cannot
see each other, and two evidence documents under the phase's own evidence directory.

<planner_findings>
Three things the planner found that none of the offered options contained. CONTEXT.md's
own standing rule says a planner who finds such a constraint should say so in writing
rather than implement an option as originally worded, so they are stated here and this
plan's evidence task records them.

1. **"No B-side path in any wire field" cannot hold literally.** `AUTOSTART`, `DUMP`
   and `UNDUMP` each carry a filename field, the emulator runs on the broker's host,
   and the Phase 63 relay is byte-transparent by design and must not parse what it
   relays. Something therefore has to carry the broker's chosen path across to the
   emulator, and that something is the client relaying a string it did not choose.
   What IS provable, and what this plan asserts, is: no broker-side path in any TOOL
   RESULT, and no client-CHOSEN broker path anywhere. The narrowing is recorded in
   the evidence, not papered over.

2. **The convergence metric's expected value of 4 appears to be off by one.**
   `STATE.md` names six current importers — `containerpath.ts`, `host-tool-client.ts`,
   `install-resources.ts`, `stock-machine.ts`, `stock-paths.ts`, `vice-proxy.ts` —
   and this phase drops exactly one of them, `stock-machine.ts`, which lands the count
   at 5 rather than the 4 `ROADMAP.md` predicts. Measured 2026-09-23 by grepping every
   non-test `.ts`/`.mts` under `src/` for imports of the three modules. D-18 already
   says the metric is measured and recorded rather than gated, so this is recorded as
   a finding for Phase 66 to reconcile, NOT forced to 4 by inventing extra work.

3. **`vsf-slice.ts` does not call `snapshotPathFor()`** — its reference is a comment
   only. CONTEXT.md asked for this to be verified rather than assumed; it is verified,
   and nothing there breaks.
