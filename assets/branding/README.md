# C64 RE Tools branding

The project logo draws on the Commodore-era open **C**, five-color rainbow, and bold **64**, with **RE TOOLS** underneath.

| Asset | Use |
| --- | --- |
| [Dark horizontal logo](c64-re-tools-dark.svg) | Main GitHub README banner and dark backgrounds |
| [Light horizontal logo](c64-re-tools-light.svg) | White or light backgrounds |
| [Transparent horizontal logo](c64-re-tools-transparent.svg) | Dark backgrounds when a transparent image is required |
| [Square icon](c64-re-tools-icon.svg) | Square avatars and app/tool icons |

These are editable vector SVG renditions based on the approved logo concept, not pixel-identical conversions of the original generated PNG. For best results use the dark or light background version on GitHub.
