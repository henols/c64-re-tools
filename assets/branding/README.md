# C64 RE Tools branding

The project logo draws on the Commodore-era open **C**, five-color rainbow, and bold **64**, with **RE TOOLS** underneath.

| Asset | Use |
| --- | --- |
| [Dark horizontal logo](c64-re-tools-dark.svg) | Transparent background with light lettering for dark surfaces |
| [Light horizontal logo](c64-re-tools-light.svg) | White or light backgrounds |
| [Transparent horizontal logo](c64-re-tools-transparent.svg) | Transparent backgrounds, with dark lettering; recommended for the main README |
| [Square icon](c64-re-tools-icon.svg) | Square avatars and app/tool icons |

These are editable vector SVG renditions based on the approved logo concept, not pixel-identical conversions of the original generated PNG. The main README displays the transparent dark-lettering logo at 440 px width. The dark and light versions are optional alternatives.
