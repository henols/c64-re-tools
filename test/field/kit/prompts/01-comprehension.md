# Comprehension probe

Do this before any other work in this project. Use the c64-field-debug skill.

1. List every skill in `.claude/skills` whose name starts with `c64-`, and every MCP tool whose name starts with `c64_`. Read only the SKILL.md files and the tool descriptions. Do not read the scripts.
2. For each skill and each tool, write one note with `--kind comprehension --component <name>`. The text has three parts of one or two sentences each. Part one: what it does. Part two: when you would use it. Part three: what you are not sure of.
3. Write one more note with `--kind comprehension --component workflow`. Say, in your own words, how the skills and the tools work together for two tasks. Task one: build and test a new program. Task two: reverse engineer an unknown program.
4. Stop, and say that you completed the probe.
